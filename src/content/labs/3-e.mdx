### 1 - Problemet med hårdkodad HTML
Första veckan skapade du en landningssida, och förra veckan fyllde du på den med hårdkodad HTML för varje labb. Detta fungerar för få laborationer, men blir snabbt problem.

**Exempel på problemet:**
```html
<!-- Hårdkodad HTML - svår att underhålla -->
<ul>
  <li class="lab-card">
    <h3>Labb 1a - Moduler</h3>
    <p>Lär dig om import och export i JavaScript</p>
    <span class="status completed">Klar</span>
  </li>
  <li class="lab-card">
    <h3>Labb 1b - Git grunder</h3>
    <p>Versionshantering med Git och GitHub</p>
    <span class="status in-progress">Pågående</span>
  </li>
  <!-- ... 20+ laborationer mer? -->
</ul>
```

**Problem med detta:**
- Mycket repetition (varje labb kräver samma HTML-struktur)
- Risk för slarvfel och inkonsistens
- Svårt att ändra utseende på alla labbar samtidigt
- Svårt att lägga till ny funktionalitet (t.ex. filtrering)

#### Övning
1. Reflektera över din nuvarande landing page:
   - Hur många laborationer har du hittills?
   - Hur många rader HTML är det per labb?
   - Vad skulle hända om du ville lägga till en "favorit"-stjärna på varje labb?

**Den datadrivna lösningen**: Istället för att hårdkoda HTML beskriver vi laborationerna som data och genererar HTML med JavaScript.

<details>
<summary>Fördelar med datadriven approach</summary>

- **Skalbarhet**: Lätt att lägga till nya labbar
- **Konsistens**: Alla labbar ser identiska ut
- **Flexibilitet**: Enkelt att ändra layout för alla labbar
- **Funktionalitet**: Enkelt att lägga till interaktivitet, sortering, filtrering osv.
- **Underhåll**: Ändringar på ett ställe påverkar alla labbar
</details>

### 2 - Designa din datastruktur
Börja med att planera hur du vill representera laborationerna som data.

#### Övning
1. **Planera din struktur**: Vilka egenskaper behöver du för dina laborationer? Fundera på:
   - Vilken information vill du visa?
   - Vill du kunna länka vissa men inte andra?

2. **Skapa din lab-array**
   * I en separat javascript fil `labs.js`, skapa en array med objekt som beskriver dina laborationer. Börja med de egenskaper som du redan visar på sidan i din hårdkodade HTML, till exempel:
    ```javascript
    export const labs = [
      {
        id: '1a',
        title: 'Moduler',
        description: 'Import och export i JavaScript',
      },
      {
        // ...
      }
      // resten av laborationerna...
    ];
    ```

3. **Testa datat**
   * Importera datat till `index.js` och logga ut den därifrån så att du ser att det fungerar.

4. **Utöka datat**: Lägg till fler egenskaper som:
   - `week`: Vilken vecka labben tillhör
   - `completed`: Boolean för om labben är avklarad
   - `hasLink`: Boolean för om labben har en länk eller inte
   - `difficulty`: T.ex. 'easy', 'medium', 'hard'
   - `topics`: En array med nyckelord/tags för labben

### 3 - Generera HTML från data med createElement
Nu kommer kärnan: vi ska skriva JavaScript som omvandlar vår data till HTML. Vi använder `document.createElement()` och `append()` som du lärde dig i förra laborationen.

**Exempel på renderingsfunktion med createElement:**
```javascript
function createLabCard(lab) {
  // Skapa huvudcontainern
  const card = document.createElement('div');
  card.classList.add('lab-card');

  card.innerHTML = `
    <h3>Labb ${lab.id} - ${lab.title}</h3>
    <p>${lab.description}</p>
    <div class="lab-meta">
      <span class="status ${lab.completed ? 'completed' : ''}"></span>
      <span class="week">Vecka ${lab.week}</span>
    </div>
    ${lab.hasLink ? `<a href="./${lab.id}/" class="lab-link">Öppna labb</a>` : ''}
  `;

  return card;
}

function renderLabs(labsToShow) {
  const container = document.getElementById('labs-container');

  // Rensa befintligt innehåll
  container.innerHTML = '';

  // Skapa och lägg till kort för varje labb
  for (const lab of labsToShow) {
    const card = createLabCard(lab);
    container.append(card);
  }
}

// Rendera vid sidladdning
renderLabs(labs);
```

#### Övning
1. **Implementera funktionerna**:
   - Skapa `createLabCard()` som returnerar ett komplett lab-kort
   - Skapa `renderLabs()` som loopar genom arrayen och lägger till korten

2. **Anpassa efter din HTML-mall**: Använd den HTML-struktur du sparade från step 3.

3. **Testa**: Kalla `renderLabs()` vid slutet av din JS-fil. Sidan ska nu visa dina labbar!

4. **Hantera villkorlig rendering**:
   - Visa länk bara om `hasLink` är true

#### Spara status med localStorage
Integrera localStorage för att spara och ladda statusen på dina laborationer:

**Funktionalitet att implementera:**
1. **Spara status**: När användaren klickar på en labb, växla satus på `completed` och spara till localStorage
2. **Ladda status**: Vid sidladdning, läs sparad status och uppdatera labs-arrayen

<details>
<summary>Tips</summary>
- Använd `lab.id` för att skapa unika nycklar i localStorage
- Använd `JSON.stringify` och `JSON.parse` för att spara/ läsa data. Kom ihåg att localStorage bara sparar strängar.
</details>

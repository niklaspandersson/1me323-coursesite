### 2 - Ladda och visa data
Nu ska vi ersätta den hårdkodade HTML:en med dynamiskt genererad.

1. Skapa en `main.js` i labs-roten (om du inte redan har en) och länka in den i `index.html`.

2. Hämta JSON-filen:

```javascript
async function loadLabs() {
  try {
    const response = await fetch("labs.json");
    if (!response.ok) throw new Error("Kunde inte ladda data");
    const data = await response.json();
    renderLabs(data);
  } catch (error) {
    console.error(error);
    // Visa felmeddelande för användaren
  }
}
```

3. Skapa en funktion `renderLabs(data)` som genererar HTML för varje vecka och laboration.

4. Ta bort den hårdkodade listan från HTML och låt JavaScript skapa den istället.

### 3 - Generera HTML dynamiskt
Du har flera alternativ för att skapa HTML från data.

#### Template literals
```javascript
function renderWeek(week) {
  const labsHtml = week.labs
    .map(lab => `
      <li>
        <a href="${lab.id}/">${lab.title}</a>
        <p>${lab.description}</p>
      </li>
    `)
    .join("");

  return `
    <section>
      <h2>Vecka ${week.number}: ${week.title}</h2>
      <ul>${labsHtml}</ul>
    </section>
  `;
}
```

#### DOM-metoder
```javascript
function renderWeek(week) {
  const section = document.createElement("section");
  const heading = document.createElement("h2");
  heading.textContent = `Vecka ${week.number}: ${week.title}`;
  section.appendChild(heading);
  // ... fortsätt bygga DOM
  return section;
}
```

Välj den metod du föredrar och rendera hela listan.

### 5 - Lägg till interaktivitet
Gör det möjligt att uppdatera status direkt på sidan.

1. Lägg till en mekanism för att markera en lab som klar (t.ex. en checkbox eller klickbar ikon).

2. När status ändras:
   * Uppdatera JSON-datan i minnet
   * Spara till localStorage
   * Uppdatera visningen

```javascript
function toggleLabStatus(weekIndex, labId) {
  const lab = data.weeks[weekIndex].labs.find(l => l.id === labId);
  lab.status = lab.status === "completed" ? "not-started" : "completed";

  // Spara till localStorage
  localStorage.setItem("labsData", JSON.stringify(data));

  // Uppdatera visningen
  renderLabs(data);
}
```

3. Vid sidladdning, försök först läsa från localStorage:

### 7 - Utmaning: Statistik
Lägg till en sammanfattning högst upp på sidan:

* Totalt antal laborationer
* Antal klara laborationer
* Procent slutfört
* Eventuellt en progressbar

```javascript
function calculateStats(weeks) {
  const allLabs = weeks.flatMap(week => week.labs);
  const completed = allLabs.filter(lab => lab.status === "completed");

  return {
    total: allLabs.length,
    completed: completed.length,
    percentage: Math.round((completed.length / allLabs.length) * 100)
  };
}
```

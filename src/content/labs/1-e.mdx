<main>
Nu när du har en mappstruktur och versionshantering på plats är det dags att skapa en startsida för ditt labs-repository. Detta blir din "portfolio" för kursen - en plats där du enkelt kan navigera till alla dina laborationer.

**En sida som växer med dig**: Vi kommer att återvända till denna startsida flera gånger under kursens gång. Allt eftersom du lär dig nya tekniker kommer du att förbättra sidan - till exempel göra den datadriven med JSON och `fetch` och lägga till dynamisk rendering.

### 0 - Förberedelser
Se till att du har `labs`-mappen öppen i VS Code och att Git är initierat (från tidigare laborationer).

Din mappstruktur bör se ut ungefär så här:
```
labs/
├── .gitignore
└── 1a/
    ├── index.html
    ├── main.js
    ├── utils.js
    └── constants.js
```

### 1 - Skapa startsidan
Skapa en `index.html` direkt i `labs`-mappen (inte i `1a`). Detta blir din startsida.

Tänk igenom vilken information som bör finnas på sidan:
* En rubrik och kort beskrivning av vad repositoryt innehåller
* En lista över laborationer, grupperade per vecka
* Varje laboration bör ha en länk, titel och kort beskrivning
   * Denna veckan är det bara laboration 1-a som behöver länkas, då de andra inte har något eget innehåll. Men lista de andra laborationerna också med titel åtminstone. 
* Information om vem som skapat sidan

Använd semantiska HTML-element för att strukturera innehållet. Tänk på vilka element som passar för de olika delarna av sidan (`<header>`, `<main>`, `<footer>`, `<section>`, `<nav>`, etc.).

### 2 - Relativa länkar
När du skapar länkar till dina laborationer, använd **relativa sökvägar**:

```html
<a href="1a/index.html">Lab 1a</a>
```

<details>
<summary>Varför relativa sökvägar?</summary>

Relativa sökvägar gör att din sida fungerar oavsett var den ligger:
* `1a/index.html` - relativ (bra!)
* `/Users/namn/labs/1a/index.html` - absolut (fungerar bara på din dator)
* `file:///C:/labs/1a/index.html` - absolut med protokoll (fungerar inte alls på webben)

Med relativa sökvägar kan du flytta hela `labs`-mappen eller lägga upp den på en webbserver utan att behöva ändra något.
</details>

### 3 - Grundläggande styling
Skapa en `global.css` i `labs`-mappen och länka in den i din HTML.

Genom att kalla filen `global.css` signalerar du att detta är gemensam styling som kan återanvändas. Du kan sedan länka in samma fil från dina individuella laborationer:

```html
<!-- Från labs/1a/index.html -->
<link rel="stylesheet" href="../global.css">
```

Styla sidan så att den blir läsbar och visuellt tilltalande. Några saker att tänka på:
* Begränsa textbredden för bättre läsbarhet
* Använd tillräckligt med whitespace (padding/margin)
* Ge länkarna tydlig styling

Experimentera och hitta en stil du tycker om!

### 4 - Committa din startsida
Spara ditt arbete i Git:

1. Öppna Source Control-panelen i VS Code.
2. Stagea de nya filerna (`index.html`, `global.css`,).
3. Skriv ett beskrivande commit-meddelande.
4. Klicka **Commit**.

### 5 - Skapa en README
En README-fil är standard i alla repositories. Den förklarar vad projektet innehåller och visas automatiskt på GitHub/GitLab. README-filer skrivs i Markdown-format och heter `README.md`. Markdown är ett enkelt sätt att formatera text med rubriker, listor, länkar, kodblock med mera.

#### Markdown-syntax

Markdown är ett enkelt sätt att formatera text:
* `# Rubrik` - stor rubrik (h1)
* `## Underrubrik` - mindre rubrik (h2)
* `**fet text**` - **fet text**
* `- punkt` - punktlista
* `[text](url)` - länk
* ``` `kod` ``` - inline-kod

GitHub, GitLab och VS Code visar automatiskt README.md-filer snyggt formaterade.

#### Skapa README.md
1. Skapa filen `README.md` i `labs`-mappen.

2. Skriv en beskrivning i Markdown-format. Inkludera:
   * En rubrik
   * Kort beskrivning av repositoryt
   * Ditt namn


### 5 - Committa README
Spara ditt arbete i Git:

1. Öppna Source Control-panelen i VS Code.
2. Stagea `README.md`
3. Skriv ett beskrivande commit-meddelande.
4. Klicka **Commit**.
5. Pusha ändringarna till GitHub.

### 6 - Utöka startsidan

#### Del A - Förbered för framtiden
Lägg till sektioner för kommande veckor (Vecka 2, 3, etc.) med placeholder-text som "Kommer snart...". Detta ger dig en struktur att fylla i efterhand.

#### Del B - Status-badges
Lägg till visuella indikatorer som visar vilka laborationer som är klara respektive pågående.

<details>
<summary>Förslag på implementation</summary>

HTML-struktur:
```html
<a href="1a/index.html">Lab 1a - Hello Modules</a> <span class="badge done">Klar</span>
```

CSS för badges:
```css
.badge {
  display: inline-block;
  padding: 0.2rem 0.5rem;
  border-radius: 4px;
  font-size: 0.75rem;
  font-weight: 600;
  margin-left: 0.5rem;
}

.badge.done {
  background-color: #c6f6d5;
  color: #276749;
}

.badge.wip {
  background-color: #fefcbf;
  color: #975a16;
}
```
</details>

#### Del C - Favicon
Lägg till en favicon för att ge sidan en mer professionell känsla.

<details>
<summary>Tips: Emoji som favicon</summary>

Du kan använda en emoji som favicon utan att skapa en bildfil:
```html
<link rel="icon" href="data:image/svg+xml,<svg xmlns='http://www.w3.org/2000/svg' viewBox='0 0 100 100'><text y='.9em' font-size='90'>🧪</text></svg>">
```
</details>

### 7 - Slutlig mappstruktur
Efter denna laboration bör din mappstruktur se ut så här:

```
labs/
├── .gitignore
├── index.html      ← Startsidan
├── global.css      ← Gemensam styling
├── README.md       ← Dokumentation
└── 1a/
    ├── index.html
    ├── main.js
    └── math.js
```

**Glöm inte** att committa och pusha dina ändringar när du är klar med utmaningarna!

### 1 - Lägga till metoder
En metod definieras direkt i klassen, på samma nivå som `constructor`. Metoder har tillgång till objektets egenskaper via `this`.

**Exempel:**
```javascript
class Dog {
  constructor(name, breed) {
    this.name = name;
    this.breed = breed;
  }

  bark() {
    console.log(`${this.name} säger: Voff!`);
  }

  describe() {
    return `${this.name} är en ${this.breed}`;
  }
}

const dog = new Dog("Fido", "Labrador");
dog.bark();                    // "Fido säger: Voff!"
console.log(dog.describe());   // "Fido är en Labrador"
```

Notera att metoder skrivs **utan** `function`-nyckelordet — samma korta syntax som vi använde för metoder i objekt-literaler.

### 2 - Metoder som ändrar tillstånd
Metoder kan inte bara läsa egenskaper — de kan också ändra dem. Det är så objekt hanterar sitt eget tillstånd.

**Exempel:**
```javascript
class Counter {
  constructor(startValue = 0) {
    this.value = startValue;
  }

  increment() {
    this.value++;
  }

  decrement() {
    this.value--;
  }

  reset() {
    this.value = 0;
  }
}

const counter1 = new Counter();
const counter2 = new Counter(100);

counter1.increment();
counter1.increment();
console.log(counter1.value); // 2

counter2.decrement();
console.log(counter2.value); // 99

// counter1 påverkas inte av vad vi gör med counter2 — de är helt isolerade
counter1.reset();
console.log(counter1.value); // 0
console.log(counter2.value); // 99 fungerar fortfarande oberoende
```

#### Övning

3. Lägg till en metod `getTotal()` som returnerar det totala antalet varor (summan av alla `quantity`).
4. Lägg till en metod `listItems()` som loggar alla varor till konsolen.

```javascript
class ShoppingCart {
  constructor() {
    this.items = [];
  }

  addItem(item) {
    this.items.push({ name: item, quantity: 1 });
  }

  getTotal() {
    let total = 0;
    for (const item of this.items) {
      total += item.quantity;
    }
    return total;
  }

  listItems() {
    for (const item of this.items) {
      console.log(`${item.name} (${item.quantity} st)`);
    }
  }
}

const cart = new ShoppingCart();
cart.addItem("Äpple");
cart.addItem("Bröd");
cart.addItem("Mjölk");

cart.listItems();
// Äpple (1 st)
// Bröd (1 st)
// Mjölk (1 st)

console.log("Totalt antal:", cart.getTotal()); // 3
```

### 3 - Problemet med `this` och händelsehantering
Nu kommer vi till en viktig skillnad som ofta ställer till problem. En **vanlig funktion** får sitt `this` beroende på var den **körs** (anropas). Det innebär att `this` kan ändras om funktionen anropas i ett annat sammanhang än där den skapades.

En **arrow-funktion** däremot får sitt `this` från var den **definieras**. Den "låser" `this` till den omgivande kontexten (din klassinstans) och behåller det värdet oavsett var funktionen senare körs.

Det här spelar ingen roll i vanliga fall, men det blir viktigt i vissa situationer — till exempel i **event-lyssnare** och **callbacks**.

**Exempel — det fungerar:**
```javascript
class Timer {
  constructor() {
    this.seconds = 0;
  }

  start() {
    // Arrow-funktion i setTimeout får samma this som start() har
    setInterval(() => {
      this.seconds++;
      console.log(this.seconds);
    }, 1000);
  }
}

const timer = new Timer();
timer.start(); // 1, 2, 3, 4...
```

Här fungerar `this.seconds` i arrow-funktionen eftersom arrow-funktioner får `this` från `start()`, som i sin tur har `this` satt till Timer-objektet.

**Exempel — det fungerar INTE:**
```javascript
class Timer {
  constructor() {
    this.seconds = 0;
  }

  start() {
    // Vanlig funktion i setInterval — this pekar INTE på timer-objektet!
    setInterval(function() {
      this.seconds++; // PROBLEM: this är inte Timer-objektet
      console.log(this.seconds);
    }, 1000);
  }
}

const timer = new Timer();
timer.start(); // NaN, NaN, NaN...
```

Här använder vi en vanlig `function` i `setInterval`. Eftersom `this` för vanliga funktioner bestäms **när funktionen körs** (och inte när den definieras), så kommer `this` att peka fel när `setInterval` väl kör koden. Kopplingen till `Timer`-objektet tappades bort i samma ögonblick som funktionen skickades iväg.

#### Tumregel
* **Klassmetoder**: Använd vanlig syntax (`metodNamn() { ... }`)
* **Callbacks inuti metoder** (t.ex. i `setTimeout`, `setInterval`, event-lyssnare): Använd **arrow-funktioner** (`() => { ... }`)

<details>
<summary>Förklaring</summary>

Med en vanlig `function` i `addEventListener` pekar `this` på **elementet som klickades** (knappen), inte på `Clicker`-objektet. Då fungerar inte `this.count` som förväntat.

```javascript
// Med vanlig function: this === knappen
button.addEventListener("click", function() {
  this.count++; // this är button-elementet, inte Clicker!
  console.log(this); // <button id="click-btn">...</button>
});
```

Det är därför arrow-funktioner är bäst för callbacks i klassmetoder — de behåller den `this` du förväntar dig.

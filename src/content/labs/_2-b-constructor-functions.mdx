### 2 - Konstruktor funktioner - en mall för objekt
En konstruktor funktion är en vanlig funktion som används som "mall" för att skapa objekt.

**Exempel:**
```javascript
// Konstruktor funktion (börjar med stor bokstav per konvention)
function Person(firstName, lastName, age) {
  this.firstName = firstName;
  this.lastName = lastName;
  this.age = age;
}

// Skapa objekt med 'new'-nyckelordet
const anna = new Person("Anna", "Andersson", 25);
const erik = new Person("Erik", "Eriksson", 30);
const maria = new Person("Maria", "Johansson", 28);

console.log(anna.firstName); // "Anna"
console.log(erik.age);       // 30
```

**Vad händer här?**
1. `new Person()` skapar ett nytt tomt objekt
2. `this` inuti funktionen refererar till det nya objektet
3. Egenskaper läggs till på objektet via `this.egenskap = värde`
4. Det nya objektet returneras automatiskt

#### Övning

### 3 - Vad är `this`?
I en constructor function refererar `this` till det objekt som håller på att skapas.

**Visualisering av vad som händer:**
```javascript
function Person(name, age) {
  // new Person() skapar ett tomt objekt: {}
  // this refererar nu till detta objekt
  
  this.name = name;  // {} blir { name: "Anna" }
  this.age = age;    // { name: "Anna" } blir { name: "Anna", age: 25 }
  
  // Objektet returneras automatiskt
}

const anna = new Person("Anna", 25);
// anna är nu { name: "Anna", age: 25 }
```

<details>
<summary>Förklaring av vad som händer utan 'new'</summary>

Utan `new`-nyckelordet:
- Inget nytt objekt skapas
- `this` refererar till `window` (globalt objekt) eller `undefined` (i strict mode)
- Du förorenar det globala scopet eller får fel
- Funktionen returnerar `undefined` istället för ett objekt

**Därför**: Använd alltid `new` med constructor functions!
</details>

### 4 - Constructor vs vanlig funktion
Viktiga skillnader att komma ihåg:

| Constructor Function | Vanlig Funktion |
|---------------------|----------------|
| Börjar med stor bokstav (konvention) | Börjar med liten bokstav |
| Anropas med `new` | Anropas direkt |
| `this` refererar till nytt objekt | `this` refererar till anroparen |
| Returnerar nytt objekt automatiskt | Måste explicit returnera värde |

#### Övning
**Debugging-övning**: Hitta och fixa problemen i denna kod:

```javascript
// Problem 1: Vad är fel här?
function calculator(initialValue) {
  this.value = initialValue;
  this.add = function(num) {
    this.value += num;
  };
}

const calc = calculator(10); // Utan 'new'
calc.add(5); // Vad händer?

// Problem 2: Vad händer här?
function Counter() {
  this.count = 0;
  this.increment = function() {
    this.count++;
  };
  return "Detta returneras istället"; // Explicit return
}

const counter = new Counter();
console.log(counter); // Vad blir resultatet?
```

<details>
<summary>Lösningar</summary>

**Problem 1**: Glömt `new`-nyckelordet. `calc` blir `undefined`.
```javascript
const calc = new calculator(10); // Lägg till 'new'
```

**Problem 2**: Explicit `return` av primitiv typ ignoreras i constructor functions, men returnar man ett objekt så används det istället för det skapade objektet. Bästa praxis är att inte ha explicit `return` alls i constructors.
```javascript
function Counter() {
  this.count = 0;
  this.increment = function() {
    this.count++;
  };
  // Ta bort explicit return
}
```
</details>

### 5 - Utmaning: Produktkatalog
Skapa en produktkatalog där du använder constructor functions för att hantera produkter.

#### Uppgift
1. **Constructor**: Skapa en `Product`-constructor med:
   - `name`, `price`, `category`, `inStock` (boolean)

2. **Data**: Skapa en array med minst 5 produkter från olika kategorier

3. **HTML**: Bygg en sida som visar alla produkter i ett snyggt grid

4. **Funktionalitet**:
   - Visa alla produkter med namn, pris och lagerstatus
   - Produkter som inte finns i lager ska markeras visuellt (t.ex. grå bakgrund)

<details>
<summary>Grund-struktur</summary>

```javascript
function Product(name, price, category, inStock) {
  this.name = name;
  this.price = price;
  this.category = category;
  this.inStock = inStock;
}

// Skapa produkter
const products = [
  new Product("Laptop", 12999, "Elektronik", true),
  new Product("Bok", 199, "Böcker", true),
  new Product("Hörlurar", 899, "Elektronik", false),
  // ... fler produkter
];

// Visa produkter
function displayProducts() {
  const container = document.getElementById('products');

  for (const product of products) {
    const html = `
      <div class="product ${product.inStock ? '' : 'out-of-stock'}">
        <h3>${product.name}</h3>
        <p class="price">${product.price} kr</p>
        <p class="category">${product.category}</p>
        <span class="stock">${product.inStock ? 'I lager' : 'Slut'}</span>
      </div>
    `;
    container.innerHTML += html;
  }
}

displayProducts();
```
</details>

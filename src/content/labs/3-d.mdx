Hittills har vi främst skapat HTML genom att konkatenera strängar och sätta `innerHTML`. Det fungerar, men det finns sätt som är både mer flexibla och robusta: att skapa riktiga DOM-element med `document.createElement()` och lägga till dem med exempelvis `append()`.

### 0 - Förberedelser
Skapa en ny mapp `3d` i din `labs`-mapp med `index.html` och `index.js`, länka även in din globala CSS. Förbered HTML:en med en tom `<main>`-tagg.

### 1 - Problemet med innerHTML

Att bygga HTML som strängar har flera nackdelar:

**Problem:**
- Svårt att lägga in element på en godtycklig plats i DOM-trädet (t.ex. mellan två barn-element).
- Varje gång du sätter `innerHTML` tas alla befintliga element bort och skapas om (detta raderar även eventuella event listeners på dessa element)

### 2 - Skapa element med createElement()

`document.createElement()` skapar ett nytt DOM-element:

```javascript
// Skapa ett nytt p-element
const paragraph = document.createElement('p');

// Sätt textinnehåll
paragraph.textContent = 'Hej från JavaScript!';

// Lägg till CSS-klass
paragraph.classList.add('highlight');

// Sätt attribut
paragraph.id = 'greeting';
```

Elementet existerar nu i minnet, men syns inte på sidan ännu eftersom det inte är tillagt i DOM-trädet.

#### Övning
Skapa tre olika element med `createElement()`:
1. En `<h1>` med texten "Min första createElement"
2. En `<p>` med en CSS-klass `"description"` och valfri text
3. En `<button>` med texten "Klicka mig"

Logga ut elementen i konsolen för att se vad de innehåller.

<summary>Lösningsförslag</summary>

### 3 - Lägg till element i DOM 

För att visa element på sidan kan vi använda `append()`. `append()` lägger till ett eller flera element som barn till ett föräldraelement, efter alla befintliga barn:

```javascript
const container = document.querySelector('main');

// Skapa element
const heading = document.createElement('h2');
heading.textContent = 'Välkommen!';

const paragraph = document.createElement('p');
paragraph.textContent = 'Detta skapades med JavaScript.';

// Lägg till i container
container.append(heading);
container.append(paragraph);

// Eller lägg till flera samtidigt
container.append(heading, paragraph);
```

#### Andra metoder för att lägga till element:
- `prepend()`: Lägger till element som *första* barn i elementet som `prepend()` anropas på
- `before()`: Lägger till element som *syskon*, *före* elementet som `before()` anropas på
- `after()`: Lägger till element som *syskon*, *efter* elementet som `after()` anropas på

**Fördel med att manipulera DOM direkt istället för via innerHTML:**
- Mer kontroll över var element placeras
- Befintliga element och event listeners bevaras

### 4 - Bygga strukturer

När du behöver byga upp mer komplexa strukturer, alltså *nästlade element*, Så finns två alternativ.


#### 1. Skapa alla delar med `createElement`:
Detta ger mest kontroll, och till exempel eventlyssnare kan kopplas på rätt element direkt.

```javascript
// Bygg en lista med createElement
function createList(items) {
  // skapa ul-element
  const ul = document.createElement('ul');

  //för varje item, skapa li och lägg till i ul
  for (const item of items) {
    const li = document.createElement('li');
    li.textContent = item;
    ul.append(li);
  }

  // returnera den färdiga listan
  return ul;
}

const fruits = ['Äpple', 'Banan', 'Citron'];
const fruitList = createList(fruits);
document.querySelector('main').append(fruitList);
```

#### 2. Kombinera `createElement` med `innerHTML` för barn:
Detta kan vara enklare när du har en djup struktur. Eventlyssnare *går* att koppla på efteråt. 

```javascript
// Bygg en lista med createElement och innerHTML
function createList(items) {
  // skapa ul-element  
  const ul = document.createElement('ul');

  // för varje item, bygg upp innerHTML som html-sträng
  let html = '';
  for (const item of items) {
    html += `<li>${item}</li>`;
  }
  // sätt innerHTML på ul
  ul.innerHTML = html;

  // returnera den färdiga listan
  return ul;
}
```

function createCard(title, description) {

### 6 - Praktisk tillämpning: Rendera data

Låt oss tillämpa detta på att visa data:

```javascript
const users = [
  { name: 'Anna', role: 'Admin' },
  { name: 'Erik', role: 'User' },
  { name: 'Maria', role: 'User' }
];

function renderUsers(users) {
  const container = document.querySelector('#user-list');

  // Rensa befintligt innehåll
  container.innerHTML = '';

  for (const user of users) {
    const div = document.createElement('div');
    div.classList.add('user-card');

    const name = document.createElement('h3');
    name.textContent = user.name;

    const role = document.createElement('span');
    role.textContent = user.role;
    role.classList.add('role', user.role.toLowerCase());

    div.append(name, role);
    container.append(div);
  }
}

renderUsers(users);
```

#### Övning
Modifiera `renderUsers` så att varje kort har en "Ta bort"-knapp som tar bort just det kortet när man klickar.
För att ta bort ett element från DOM kan du använda `element.remove()`.

<details>
<summary>Tips</summary>
Skapa knappen inuti loopen och lägg till en click-eventlyssnare som anropar `div.remove()`.
</details>

<details>
<summary>Lösningsförslag</summary>
```javascript
const deleteBtn = document.createElement('button');
deleteBtn.textContent = 'Ta bort';
deleteBtn.addEventListener('click', () => {
  div.remove(); // Tar bort elementet från DOM
});
div.append(name, role, deleteBtn);
```
</details>

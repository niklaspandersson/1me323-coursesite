Hittills har vi fokuserat på att visa och validera formulär. Nu ska vi skicka datan någonstans! Vi lär oss hantera submit-eventet, samla in data, och kommunicera med en server.

### 0 - Förberedelser
Skapa en ny mapp `7c` i din `labs`-mapp med `index.html` och `main.js`. Länka gärna in `global.css`.

Bygg ett enkelt formulär med några fält (namn, e-post, meddelande).

### 1 - Hantera submit-eventet
Standardbeteendet för formulär är att ladda om sidan. Vi vill ofta förhindra det.

```javascript
const form = document.querySelector("#contact-form");

form.addEventListener("submit", (e) => {
  e.preventDefault(); // Förhindra omladdning

  console.log("Formulär skickat!");
});
```

**Viktigt**: `e.preventDefault()` måste anropas för att stoppa standardbeteendet.

### 2 - Samla in data med FormData
`FormData` är ett inbyggt objekt som samlar alla värden från ett formulär.

```javascript
form.addEventListener("submit", (e) => {
  e.preventDefault();

  const formData = new FormData(form);

  // Läs enskilda värden
  console.log(formData.get("name"));
  console.log(formData.get("email"));

  // Iterera över alla fält
  for (const [key, value] of formData.entries()) {
    console.log(`${key}: ${value}`);
  }
});
```

**OBS**: Varje fält måste ha ett `name`-attribut för att inkluderas i FormData!

### 3 - Konvertera till olika format
FormData kan användas direkt med fetch, eller konverteras:

```javascript
// Till vanligt objekt
const data = Object.fromEntries(formData);
console.log(data); // { name: "Anna", email: "anna@example.com" }

// Till JSON-sträng
const json = JSON.stringify(Object.fromEntries(formData));

// Till URL-encoded (för GET-parametrar)
const params = new URLSearchParams(formData);
console.log(params.toString()); // "name=Anna&email=anna%40example.com"
```

### 4 - Skicka med fetch (POST)
Nu ska vi skicka datan till en server. Vi använder JSONPlaceholder för testning.

```javascript
async function submitForm(formData) {
  const response = await fetch("https://jsonplaceholder.typicode.com/posts", {
    method: "POST",
    headers: {
      "Content-Type": "application/json"
    },
    body: JSON.stringify(Object.fromEntries(formData))
  });

  if (!response.ok) {
    throw new Error(`Server svarade med ${response.status}`);
  }

  return response.json();
}

form.addEventListener("submit", async (e) => {
  e.preventDefault();

  const formData = new FormData(form);

  try {
    const result = await submitForm(formData);
    console.log("Svar från server:", result);
    // Visa bekräftelse för användaren
  } catch (error) {
    console.error("Fel:", error);
    // Visa felmeddelande för användaren
  }
});
```

### 5 - Visa status för användaren
Ge användaren feedback under hela processen.

```javascript
const submitButton = form.querySelector('button[type="submit"]');
const statusDiv = document.querySelector("#form-status");

form.addEventListener("submit", async (e) => {
  e.preventDefault();

  // Visa laddning
  submitButton.disabled = true;
  submitButton.textContent = "Skickar...";
  statusDiv.textContent = "";
  statusDiv.className = "";

  const formData = new FormData(form);

  try {
    const result = await submitForm(formData);

    // Visa bekräftelse
    statusDiv.textContent = "Tack! Ditt meddelande har skickats.";
    statusDiv.className = "success";
    form.reset(); // Töm formuläret

  } catch (error) {
    // Visa fel
    statusDiv.textContent = "Något gick fel. Försök igen.";
    statusDiv.className = "error";

  } finally {
    // Återställ knapp oavsett
    submitButton.disabled = false;
    submitButton.textContent = "Skicka";
  }
});
```

### 6 - Hantera checkboxar och flerval
FormData hanterar vissa fält speciellt:

```javascript
// En enda checkbox (boolean)
// Om inte ikryssad finns den inte i FormData
const newsletter = formData.get("newsletter"); // null om inte ikryssad

// Flera checkboxar med samma name
// Returnerar bara första - använd getAll()
const allergies = formData.getAll("allergies"); // ["gluten", "laktos"]

// Select med multiple
const options = formData.getAll("options");
```

### 8 - Simulera serverfel
I verkligheten går saker fel. Testa din felhantering!

```javascript
async function submitWithRandomFailure(formData) {
  // 30% chans att misslyckas
  if (Math.random() < 0.3) {
    throw new Error("Simulerat serverfel");
  }

  return fetch("https://jsonplaceholder.typicode.com/posts", {
    method: "POST",
    body: JSON.stringify(Object.fromEntries(formData)),
    headers: { "Content-Type": "application/json" }
  }).then(r => r.json());
}
```

### 9 - Utmaning: Server-side validering
Servrar kan returnera valideringsfel. Hantera dem!

```javascript
// Simulerat svar från server med fel
const serverResponse = {
  success: false,
  errors: {
    email: "E-postadressen är redan registrerad",
    password: "Lösenordet är för svagt"
  }
};

function showServerErrors(errors) {
  // Rensa tidigare fel
  document.querySelectorAll(".field-error").forEach(el => {
    el.textContent = "";
  });

  // Visa nya fel
  for (const [field, message] of Object.entries(errors)) {
    const errorEl = document.querySelector(`#${field}-error`);
    if (errorEl) {
      errorEl.textContent = message;
    }

    // Markera fältet
    const input = document.querySelector(`#${field}`);
    if (input) {
      input.classList.add("server-error");
    }
  }
}
```

Objekt är en av de viktigaste datastrukturerna i JavaScript. De låter oss gruppera relaterad data och funktionalitet tillsammans, vilket gör koden mer organiserad och lättare att förstå.

### 0 - Förberedelser

```

├── ...
```

Skapa en `index.html` och en `main.js`. Länka in JavaScript-filen som en modul. Du kan även länka in din `global.css` från labs-mappen om du vill ha samma grundstil.

### 1 - Skapa ett objekt
Ett objekt är en samling av egenskaper (properties), där varje egenskap har ett namn (nyckel) och ett värde.

1. I `main.js`, skapa ett objekt som representerar en person:

```javascript
const person = {
  firstName: "Ada",
  lastName: "Lovelace",
  age: 36,
  occupation: "Mathematician"
};
```

2. Logga hela objektet till konsolen.

3. Logga enskilda egenskaper med **punktnotation**:
```javascript
console.log(person.firstName);
console.log(person.age);
```

4. Prova också **hakparentesnotation**:
```javascript
console.log(person["lastName"]);
```

**Testa själv**: Vad är skillnaden mellan `person.age` och `person["age"]`? När kan hakparentesnotation vara användbart?

<details>
<summary>När använder man hakparenteser?</summary>

Hakparentesnotation är nödvändig när:
* Egenskapsnamnet innehåller mellanslag eller specialtecken: `person["full name"]`
* Egenskapsnamnet är lagrat i en variabel:
```javascript
const key = "firstName";
console.log(person[key]); // "Ada"
```
* Egenskapsnamnet är ett tal: `obj[0]`
</details>

### 2 - Nästlade objekt
Objekt kan innehålla andra objekt som värden, vilket låter dig skapa mer komplexa datastrukturer.

1. Utöka ditt `person`-objekt med en nästlad `address`-egenskap:

```javascript
const person = {
  firstName: "Ada",
  lastName: "Lovelace",
  age: 36,
  address: {
    street: "St James's Square",
    city: "London",
    country: "England"
  }
};
```

2. Logga ut personens stad:
```javascript
console.log(person.address.city);
```

3. Skapa ett eget objekt som representerar något du väljer själv (en bok, en film, en bil, etc.). Inkludera minst:
   * 3-4 enkla egenskaper (strängar, tal, booleans)
   * 1 nästlat objekt
   * 1 array

<details>
<summary>Exempel på struktur</summary>

```javascript
const book = {
  title: "Frankenstein",
  author: "Mary Shelley",
  published: 1818,
  isAvailable: true,
  publisher: {
    name: "Lackington, Hughes, Harding, Mavor & Jones",
    city: "London"
  },
  genres: ["Gothic", "Science Fiction", "Horror"]
};
```
</details>

### 3 - Dynamiska egenskaper
Till skillnad från många andra programmeringsspråk kan du lägga till och ta bort egenskaper från JavaScript-objekt när som helst.

1. Lägg till en ny egenskap efter att objektet skapats:
```javascript
person.email = "ada@example.com";
console.log(person.email);
```

2. Ändra en befintlig egenskap:
```javascript
person.age = 37;
```

3. Ta bort en egenskap:
```javascript
delete person.occupation;
console.log(person.occupation); // undefined
```

4. Kontrollera om en egenskap finns:
```javascript
console.log("email" in person);      // true
console.log("phone" in person);      // false
```

**Testa själv**: Vad händer om du försöker läsa en egenskap som inte finns?

### 4 - Visa objektdata i DOM
Nu ska vi koppla ihop JavaScript-objektet med HTML för att visa datan på sidan.

1. Skapa ett HTML-element där du kan visa informationen (t.ex. en `<article>` eller `<div>` med ett id).

2. Skriv JavaScript som läser ut egenskaperna från ditt objekt och visar dem i DOM:en.

Tänk på:
* Hur vill du strukturera informationen semantiskt?
* Vilka HTML-element passar för olika typer av data?
* Hur hanterar du nästlade objekt och arrayer?

<details>
<summary>Tips för att komma igång</summary>

```javascript
const output = document.querySelector("#output");
output.innerHTML = `
  <h2>${person.firstName} ${person.lastName}</h2>
  <p>Ålder: ${person.age}</p>
`;
```

För arrayer kan du använda `join()`:
```javascript
const genres = book.genres.join(", ");
```
</details>

### 5 - Utmaning: Iterera över ett objekt
Ibland vill man loopa igenom alla egenskaper i ett objekt utan att veta namnen i förväg.

1. Använd `Object.keys()` för att få en array med alla nyckelnamn:
```javascript
const keys = Object.keys(person);
console.log(keys); // ["firstName", "lastName", "age", ...]
```

2. Använd `Object.values()` för att få alla värden:
```javascript
const values = Object.values(person);
```

3. Använd `Object.entries()` för att få par av [nyckel, värde]:
```javascript
for (const [key, value] of Object.entries(person)) {
  console.log(`${key}: ${value}`);
}
```

4. Skapa en funktion som tar ett godtyckligt objekt och genererar en HTML-lista med alla dess egenskaper (på första nivån).

<details>
<summary>Förslag på lösning</summary>

```javascript
function objectToList(obj) {
  const items = Object.entries(obj)
    .map(([key, value]) => `<li><strong>${key}:</strong> ${value}</li>`)
    .join("");
  return `<ul>${items}</ul>`;
}

output.innerHTML = objectToList(person);
```

Notera att detta bara fungerar för enkla värden - nästlade objekt kommer att visas som `[object Object]`.
</details>

<main>
HTTP är protokollet som driver webben. För att effektivt arbeta med webb-API:er behöver du förstå mer än bara `fetch` - du behöver förstå statusar, headers och hur man kommunicerar med servrar på rätt sätt.

### 0 - Förberedelser
Skapa en ny mapp `6b` i din `labs`-mapp med `index.html` och `main.js`. Länka gärna in `global.css`.

### 1 - HTTP-statusar
Varje HTTP-svar har en statuskod som berättar hur det gick.

1. Skapa en funktion som testar olika statusar:

```javascript
async function checkStatus(url) {
  try {
    const response = await fetch(url);
    console.log(`Status: ${response.status} ${response.statusText}`);
    console.log(`OK: ${response.ok}`);
    return response;
  } catch (error) {
    console.log("Nätverksfel:", error.message);
  }
}
```

2. Testa mot olika URL:er:

```javascript
// 200 OK
checkStatus("https://api.tvmaze.com/shows/1");

// 404 Not Found
checkStatus("https://api.tvmaze.com/shows/999999999");

// Nätverksfel (ogiltig URL)
checkStatus("https://finns-inte-alls.example.com");
```

3. Vanliga statuskoder:
   * **200** - OK, allt gick bra
   * **201** - Created, resurs skapades
   * **400** - Bad Request, fel i din förfrågan
   * **401** - Unauthorized, autentisering krävs
   * **403** - Forbidden, du har inte tillgång
   * **404** - Not Found, resursen finns inte
   * **500** - Internal Server Error, serverfel

### 2 - Läsa response headers
Headers innehåller metadata om svaret.

```javascript
async function inspectHeaders(url) {
  const response = await fetch(url);

  // Läs specifika headers
  console.log("Content-Type:", response.headers.get("content-type"));
  console.log("Date:", response.headers.get("date"));

  // Lista alla headers
  for (const [key, value] of response.headers.entries()) {
    console.log(`${key}: ${value}`);
  }
}

inspectHeaders("https://api.tvmaze.com/shows/1");
```

Intressanta headers att titta på:
* `content-type` - Typ av data (application/json, text/html, etc.)
* `content-length` - Storlek på svaret
* `cache-control` - Hur länge svaret kan cachas

### 3 - Skicka headers
Du kan skicka egna headers med din förfrågan.

```javascript
const response = await fetch("https://api.example.com/data", {
  headers: {
    "Accept": "application/json",
    "X-Custom-Header": "mitt-värde"
  }
});
```

Vanliga headers att skicka:
* `Accept` - Vilken typ av svar du vill ha
* `Content-Type` - Vilken typ av data du skickar
* `Authorization` - För autentisering

### 4 - API-nycklar
Många API:er kräver autentisering via en API-nyckel.

**Viktigt**: Lägg aldrig riktiga API-nycklar i frontend-kod som kan ses av användare! Detta är för lärande - i produktion hanteras nycklar på servern.

1. Skapa ett konto på ett API som kräver nyckel, t.ex. [OpenWeatherMap](https://openweathermap.org/api) (gratis).

2. Nyckeln kan skickas på olika sätt beroende på API:et:

```javascript
// Som query parameter
fetch(`https://api.example.com/data?api_key=${API_KEY}`)

// Som header
fetch("https://api.example.com/data", {
  headers: {
    "Authorization": `Bearer ${API_KEY}`
    // eller
    "X-API-Key": API_KEY
  }
})
```

3. Läs API-dokumentationen för att veta vilken metod som används.

### 5 - POST-förfrågningar
Hittills har vi bara hämtat data (GET). POST används för att skicka data till servern.

För att testa POST utan backend kan vi använda https://jsonplaceholder.typicode.com:

```javascript
async function createPost(title, body) {
  const response = await fetch("https://jsonplaceholder.typicode.com/posts", {
    method: "POST",
    headers: {
      "Content-Type": "application/json"
    },
    body: JSON.stringify({
      title: title,
      body: body,
      userId: 1
    })
  });

  const data = await response.json();
  console.log("Skapad post:", data);
  return data;
}

createPost("Min rubrik", "Innehåll i posten");
```

**Notera**: JSONPlaceholder är ett fake-API för testning. Det sparar inte datan på riktigt, men svarar som om det gjorde det.

### 6 - Praktisk övning: Header Inspector
Bygg ett verktyg som inspekterar HTTP-förfrågningar.

1. Skapa ett formulär där användaren kan:
   * Ange en URL
   * Välja metod (GET, POST)
   * Lägga till egna headers

2. Skicka förfrågan och visa:
   * Response status
   * Response headers
   * Response body (formaterat om JSON)
   * Hur lång tid det tog

3. Hantera fel gracefully.

const startTime = performance.now();

### 7 - Utmaning: Väder-app
Bygg en enkel väder-applikation.

1. Skapa ett konto på [OpenWeatherMap](https://openweathermap.org/api) och få en API-nyckel.

2. Bygg ett gränssnitt där användaren kan:
   * Söka efter en stad
   * Se aktuellt väder (temperatur, väderförhållanden, etc.)

3. API-anrop:
   ```
   https://api.openweathermap.org/data/2.5/weather?q={city}&appid={API_KEY}&units=metric&lang=sv
   ```

4. Visa relevant information:
   * Temperatur
   * Väderbeskrivning
   * Väderikon (API:et ger ikon-koder)
   * Vindhastighet, luftfuktighet, etc.

5. Hantera fel (stad hittades inte, API-fel, etc.)

Där `icon_code` kommer från API-svaret: `data.weather[0].icon`

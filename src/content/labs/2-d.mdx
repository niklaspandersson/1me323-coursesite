### 1 - Problemet med objekt i localStorage
I förra laborationen såg vi att localStorage bara kan spara strängar. Vad händer när vi vill spara objekt eller arrayer?

**Demonstration av problemet:**
```javascript
const user = {
  name: "Ada",
  age: 36,
  hobbies: ["matematik", "programmering"]
};

localStorage.setItem("user", user);
console.log(localStorage.getItem("user")); // "[object Object]" - trasigt!

// Även arrayer blir fel
const colors = ["röd", "grön", "blå"];
localStorage.setItem("colors", colors);
console.log(localStorage.getItem("colors")); // "röd,grön,blå" - nästan rätt, men inte en array längre
```

#### Övning
1. Skapa ett objekt `student` med:
   * `name`: ditt namn
   * `courses`: en array med kursnamn (t.ex. ["Webbteknik 2", "Programmering"])
   * `grades`: ett objekt med kurser som nycklar och betyg som värden

2. Försök spara `student` i localStorage och läs upp det.

3. Vad blir resultatet? Är det användbart?

**Reflektion**: Varför fungerar inte objekt och arrayer direkt i localStorage?

<details>
<summary>Förklaring</summary>

JavaScript anropar automatiskt `.toString()` på objektet när det konverteras till sträng. För objekt blir detta `"[object Object]"` och för arrayer blir det en kommaseparerad lista. All struktur och datatyper går förlorade.
</details>

### 2 - JSON.stringify och JSON.parse
JSON (JavaScript Object Notation) löser detta problem genom att konvertera objekt till välformatterade strängar.

**Exempel:**
```javascript
const user = { name: "Ada", age: 36, active: true };

// Konvertera objekt till JSON-sträng
const jsonString = JSON.stringify(user);
console.log(jsonString);        // '{"name":"Ada","age":36,"active":true}'
console.log(typeof jsonString); // "string"

// Konvertera tillbaka till objekt
const parsed = JSON.parse(jsonString);
console.log(parsed);        // { name: "Ada", age: 36, active: true }
console.log(typeof parsed); // "object"
console.log(parsed.name);   // "Ada"

// Nu kan vi spara i localStorage
localStorage.setItem("user", JSON.stringify(user));
const loadedUser = JSON.parse(localStorage.getItem("user"));
console.log(loadedUser.name); // "Ada"
```

#### Övning
1. Använd ditt `student`-objekt från förra övningen.

2. Konvertera det till JSON med `JSON.stringify()` och logga resultatet.

3. Konvertera JSON-strängen tillbaka till ett objekt med `JSON.parse()`.

4. Kontrollera att du kan komma åt alla egenskaper (name, courses, grades).

5. Skapa en funktion `saveStudent()` och `loadStudent()` som sparar/laddar student-objektet i localStorage:

<details>
<summary>Lösningsförslag</summary>

```javascript

  name: "Anna Andersson",
  courses: ["Webbteknik 2", "Programmering", "Databaser"],
  grades: {
    "Webbteknik 2": "A",
    "Programmering": "B",
    "Databaser": "A"
  }
};

```

### 3 - Hantera fel och saknade data
När vi arbetar med JSON och localStorage måste vi hantera två potentiella problem: saknade data och felaktig JSON.

**Exempel på säker hantering:**
```javascript
function loadFromStorage(key, defaultValue = null) {
  try {
    const item = localStorage.getItem(key);
    // Om nyckeln inte finns returnerar getItem() null
    if (item === null) {
      return defaultValue;
    }
    // Försök konvertera JSON
    return JSON.parse(item);
  } catch (error) {
    console.error("Kunde inte läsa från localStorage:", error);
    return defaultValue;
  }
}

// Användning
const user = loadFromStorage("user", { name: "Gäst", preferences: {} });
const settings = loadFromStorage("settings", { theme: "light", language: "sv" });
```

   - Laddar profilen vid sidstart (använd fallback-värden om ingen profil finns)
   - Låter användaren uppdatera profilen via formulär

<details>
<summary>Lösningsförslag för säkra funktioner</summary>

```javascript
function saveToStorage(key, data) {
  try {
    localStorage.setItem(key, JSON.stringify(data));
    return true; // Lyckades
  } catch (error) {
    console.error("Kunde inte spara till localStorage:", error);
    return false; // Misslyckades
  }
}

function loadFromStorage(key, fallback = null) {
  try {
    const item = localStorage.getItem(key);
    return item ? JSON.parse(item) : fallback;
  } catch (error) {
    console.error(`Fel vid läsning av ${key}:`, error);
    return fallback;
  }
}

// Exempel på användarprofil
const defaultProfile = {
  name: "",
  age: 0,
  interests: []
};

let userProfile = loadFromStorage("userProfile", defaultProfile);

function updateProfile(name, age, interests) {
  userProfile = { name, age, interests };
  saveToStorage("userProfile", userProfile);
}
```
</details>

### 4 - JSON-formatet fördjupning
JSON är ett textbaserat format som ser ut nästan exakt som JavaScript-objekt, men med viktiga skillnader.

**Giltigt JSON:**
```json
{
  "name": "Ada Lovelace",
  "age": 36,
  "isActive": true,
  "hobbies": ["matematik", "programmering"],
  "address": {
    "city": "London",
    "country": "England"
  }
}
```

#### Övning
1. **Validering**: Vilket av dessa JSON-exempel är korrekt? Testa med `JSON.parse()`:

```javascript
// A
const jsonA = '{"name": "Ada", "age": 36}';

// B 
const jsonB = "{'name': 'Ada', 'age': 36}";

// C
const jsonC = '{"name": "Ada", "age": 36,}';

// D
const jsonD = '{"name": "Ada", "hobbies": ["math", "coding"], "active": true}';
```

2. **Konvertering**: Ta detta JavaScript-objekt och konvertera det till giltig JSON manuellt (skriv JSON-strängen för hand):
```javascript
const product = {
  title: 'iPhone 15',
  price: 12999,
  inStock: true,
  colors: ['svart', 'vit', 'blå'],
  specs: {
    storage: '128GB',
    camera: '48MP'
  }
};
```

<details>
<summary>JSON-regler sammanfattning</summary>

**Obligatoriskt:**
- Nycklar måste ha dubbla citattecken: `"name"`
- Strängar måste ha dubbla citattecken: `"Ada"`
- Inga trailing commas: ~~`{"a": 1,}`~~

**Tillåtet:**
- Strängar, tal, booleans, null
- Objekt och arrayer (nästlade)

**Ej tillåtet:**
- Funktioner, undefined, kommentarer
- Enkla citattecken, datum-objekt
</details>

<details>
<summary>Svar på valideringsövningen</summary>

- **A**: ✅ Korrekt
- **B**: ❌ Enkla citattecken  
- **C**: ❌ Trailing comma
- **D**: ✅ Korrekt

**Manuell JSON för product:**
```json
{
  "title": "iPhone 15",
  "price": 12999,
  "inStock": true,
  "colors": ["svart", "vit", "blå"],
  "specs": {
    "storage": "128GB", 
    "camera": "48MP"
  }
}
```
</details>

### 5 - Utmaning: Shopping lista med persistens
Nu ska du bygga en komplett shopping lista som sparas automatiskt med JSON och localStorage.

#### Uppgift
Skapa en shopping lista-app med följande funktionalitet:

**Datastruktur** (som exempel):
```javascript
let shoppingList = [
  { id: 1, item: "Mjölk", category: "Mejeri", bought: false, urgent: true },
  { id: 2, item: "Bröd", category: "Bageri", bought: false, urgent: false },
  { id: 3, item: "Äpplen", category: "Frukt", bought: true, urgent: false }
];
```

**Grundfunktioner:**
1. **Lägg till vara** - formulär med fält för artikel, kategori, om det är brådskande
2. **Visa lista** - alla varor med möjlighet att kryssa av som köpt
3. **Ta bort vara** - knapp för att radera från listan  
4. **Filtrera** - visa bara "Ej köpt", "Köpt" eller "Alla"
5. **Automatisk sparning** - spara listan efter varje ändring

**Tekniska krav:**
- Använd dina säkra `saveToStorage()` och `loadFromStorage()` funktioner
- Generera unika ID:n för varje vara (t.ex. `Date.now()`)
- Hantera tom lista elegant (visa meddelande)

#### Starthjälp
1. Börja med HTML-strukturen:
   - Formulär för att lägga till vara
   - Container för listan
   - Knappar för filtrering

2. Skapa grundfunktionerna:
   - `addItem(item, category, urgent)`
   - `removeItem(id)` 
   - `toggleBought(id)`
   - `renderList(filter)`
   - `saveList()` och `loadList()`

3. Bygg funktionaliteten steg för steg och testa varje del.

<details>
<summary>Exempel på grundstruktur</summary>

```javascript
// Säkra localStorage-funktioner (från tidigare övning)
function saveToStorage(key, data) {
  try {
    localStorage.setItem(key, JSON.stringify(data));
    return true;
  } catch (error) {
    console.error("Kunde inte spara:", error);
    return false;
  }
}

function loadFromStorage(key, fallback = null) {
  try {
    const item = localStorage.getItem(key);
    return item ? JSON.parse(item) : fallback;
  } catch (error) {
    console.error("Kunde inte ladda:", error);
    return fallback;
  }
}

// Shopping lista funktioner
let shoppingList = loadFromStorage("shoppingList", []);

function addItem(item, category, urgent = false) {
  const newItem = {
    id: Date.now(),
    item: item.trim(),
    category: category.trim(),
    bought: false,
    urgent: urgent
  };
  
  shoppingList.push(newItem);
  saveList();
  renderList();
}

function saveList() {
  saveToStorage("shoppingList", shoppingList);
}

function renderList(filter = 'all') {
  const container = document.getElementById('shopping-list');
  let filteredList = shoppingList;
  
  if (filter === 'bought') {
    filteredList = shoppingList.filter(item => item.bought);
  } else if (filter === 'not-bought') {
    filteredList = shoppingList.filter(item => !item.bought);
  }
  
  if (filteredList.length === 0) {
    container.innerHTML = '<p>Ingen vara att visa</p>';
    return;
  }
  
  container.innerHTML = filteredList.map(item => `
    <div class="item ${item.bought ? 'bought' : ''} ${item.urgent ? 'urgent' : ''}">
      <input type="checkbox" ${item.bought ? 'checked' : ''} 
             onchange="toggleBought(${item.id})">
      <span>${item.item} (${item.category})</span>
      <button onclick="removeItem(${item.id})">Ta bort</button>
    </div>
  `).join('');
}

// Ladda lista vid start
renderList();
```
</details>

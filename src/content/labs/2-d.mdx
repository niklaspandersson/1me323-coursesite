### 1 - Problemet med objekt i localStorage
I förra laborationen såg vi att localStorage bara kan spara strängar. Vad händer när vi vill spara objekt eller arrayer?

**Demonstration av problemet:**
```javascript
const user = {
  name: "Ada",
  age: 36,
  hobbies: ["matematik", "programmering"]
};

localStorage.setItem("user", user);
console.log(localStorage.getItem("user")); // "[object Object]" - trasigt!

// Även arrayer blir fel
const colors = ["röd", "grön", "blå"];
localStorage.setItem("colors", colors);
console.log(localStorage.getItem("colors")); // "röd,grön,blå" - nästan rätt, men inte en array längre
```

#### Övning
1. Skapa ett objekt `student` med:
   * `name`: ditt namn
   * `courses`: en array med kursnamn (t.ex. ["Webbteknik 3", "Digitala medier"])

2. Försök spara `student` i localStorage och läs upp det.

3. Vad blir resultatet? Är det användbart?

**Reflektion**: Varför fungerar inte objekt och arrayer direkt i localStorage?

<details>
<summary>Förklaring</summary>

JavaScript anropar automatiskt `.toString()` på objektet när det konverteras till sträng. För objekt blir detta `"[object Object]"` och för arrayer blir det en kommaseparerad lista. All struktur och datatyper går förlorade.
</details>

### 2 - JSON.stringify och JSON.parse
JSON (JavaScript Object Notation) löser detta problem genom att konvertera objekt till välformatterade strängar. Javascript har inbyggda metoder för detta: `JSON.stringify()` och `JSON.parse()`.

**Exempel:**
```javascript
const user = { name: "Ada", age: 36, active: true };

// Konvertera objekt till JSON-sträng
const jsonString = JSON.stringify(user);
console.log(jsonString);        // '{"name":"Ada","age":36,"active":true}'
console.log(typeof jsonString); // "string"

// Konvertera tillbaka till objekt
const parsed = JSON.parse(jsonString);
console.log(parsed);        // { name: "Ada", age: 36, active: true }
console.log(typeof parsed); // "object"
console.log(parsed.name);   // "Ada"

// Nu kan vi spara i localStorage
localStorage.setItem("user", JSON.stringify(user));
const loadedUser = JSON.parse(localStorage.getItem("user"));
console.log(loadedUser.name); // "Ada"
```

### 3 - JSON-formatet fördjupning
JSON är ett textbaserat format som ser ut nästan exakt som JavaScript-objekt, men med viktiga skillnader.

**Giltigt JSON:**
```json
{
  "name": "Ada Lovelace",
  "age": 36,
  "isActive": true,
  "hobbies": ["matematik", "programmering"],
  "address": {
    "city": "London",
    "country": "England"
  }
}
```

#### Övning
1. **Validering**: Vilket av dessa JSON-exempel är korrekt? Testa med `JSON.parse()`:

```javascript
// A
const jsonA = '{"name": "Ada", "age": 36}';

// B 
const jsonB = "{'name': 'Ada', 'age': 36}";

// C
const jsonC = '{"name": "Ada", "age": 36,}';

// D
const jsonD = '{"name": "Ada", "hobbies": ["math", "coding"], "active": true}';
```

2. **Konvertering**: Ta detta JavaScript-objekt och konvertera det till giltig JSON manuellt (skriv JSON-strängen för hand):
```javascript
const product = {
  title: 'iPhone 15',
  price: 12999,
  inStock: true,
  colors: ['svart', 'vit', 'blå'],
  specs: {
    storage: '128GB',
    camera: '48MP'
  }
};
```

<details>
<summary>JSON-regler sammanfattning</summary>

**Obligatoriskt:**
- Nycklar måste ha dubbla citattecken: `"name"`
- Strängar måste ha dubbla citattecken: `"Ada"`
- Inga trailing commas: ~~`{"a": 1,}`~~

**Tillåtet:**
- Strängar, tal, booleans, null
- Objekt och arrayer (nästlade)

**Ej tillåtet:**
- Funktioner, undefined, kommentarer
- Enkla citattecken, datum-objekt
</details>

<details>
<summary>Svar på valideringsövningen</summary>

- **A**: ✅ Korrekt
- **B**: ❌ Enkla citattecken  
- **C**: ❌ Trailing comma
- **D**: ✅ Korrekt

**Manuell JSON för product:**

```json
  "inStock": true,
  "colors": ["svart", "vit", "blå"],
  "specs": {
    "storage": "128GB", 
    "camera": "48MP"
  }
}
```
</details>

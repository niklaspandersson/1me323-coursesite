#### Syfte
* Att förstå hur webbläsaren kan spara data lokalt.
* Att kunna använda `localStorage` för att läsa och skriva nyckel-värde-par.
* Att kunna behålla användardata mellan sidladdningar.

<main>
Ibland vill vi att webbplatsen ska "komma ihåg" saker - användarens namn, inställningar, eller var de var i ett formulär. `localStorage` ger oss ett enkelt sätt att spara data i webbläsaren som överlever både sidladdningar och att webbläsaren stängs.

### 0 - Förberedelser
Skapa en ny mapp `2c` i din `labs`-mapp med `index.html` och `main.js`. Länka gärna in `global.css`.

### 1 - Grunderna i localStorage
`localStorage` är ett enkelt nyckel-värde-lager som finns inbyggt i alla moderna webbläsare.

1. Öppna webbläsarens konsol och prova:

```javascript
// Spara ett värde
localStorage.setItem("greeting", "Hej världen!");

// Läsa ett värde
const message = localStorage.getItem("greeting");
console.log(message); // "Hej världen!"

// Ta bort ett värde
localStorage.removeItem("greeting");

// Rensa allt
localStorage.clear();
```

2. Spara ett värde och ladda om sidan. Läs sedan ut värdet igen - det finns kvar!

3. Du kan också se vad som är sparat i localStorage via DevTools:
   * Öppna DevTools (F12)
   * Gå till fliken **Application** (Chrome) eller **Storage** (Firefox)
   * Expandera **Local Storage** i sidomenyn

### 2 - Kom ihåg användarens namn
Nu ska vi bygga en sida som kommer ihåg användarens namn.

1. Skapa HTML med:
   * Ett textfält för att skriva sitt namn
   * En rubrik eller text som hälsar användaren

2. I JavaScript:
   * När sidan laddas: Kolla om det finns ett sparat namn och fyll i fältet
   * När användaren skriver: Spara värdet till localStorage

3. Lyssna på `input`-eventet för att spara direkt när användaren skriver:

```javascript
nameInput.addEventListener("input", function() {
  localStorage.setItem("userName", this.value);
});
```

4. Vid sidladdning, läs upp värdet:

```javascript
const savedName = localStorage.getItem("userName");
if (savedName) {
  nameInput.value = savedName;
}
```

5. Uppdatera även hälsningen baserat på namnet.

**Testa**: Skriv ditt namn, ladda om sidan - namnet ska finnas kvar!

### 3 - Hantera saknade värden
`localStorage.getItem()` returnerar `null` om nyckeln inte finns. Detta är viktigt att hantera.

1. Prova:
```javascript
const doesNotExist = localStorage.getItem("xyzNotHere");
console.log(doesNotExist); // null
```

2. Använd en fallback med `||` eller nullish coalescing `??`:

```javascript
// Med || (använder fallback för alla "falsy" värden)
const name = localStorage.getItem("userName") || "Gäst";

// Med ?? (använder fallback endast för null/undefined)
const name = localStorage.getItem("userName") ?? "Gäst";
```

<details>
<summary>Skillnaden mellan || och ??</summary>

```javascript
localStorage.setItem("count", "0");

// || behandlar "0" som falsy och använder fallback
const a = localStorage.getItem("count") || "10"; // "10" (fel!)

// ?? använder endast fallback för null/undefined
const b = localStorage.getItem("count") ?? "10"; // "0" (rätt!)
```

Använd `??` när tomma strängar eller "0" är giltiga värden.
</details>

### 4 - Begränsningar
localStorage har några viktiga begränsningar att känna till:

1. **Endast strängar**: Allt sparas som strängar.
```javascript
localStorage.setItem("age", 25);
const age = localStorage.getItem("age");
console.log(typeof age); // "string" (inte "number"!)
console.log(age + 5);    // "255" (strängkonkatenering!)
```

2. **Lösning för tal**:
```javascript
const age = Number(localStorage.getItem("age"));
// eller
const age = parseInt(localStorage.getItem("age"), 10);
```

3. **Objekt fungerar inte direkt**:
```javascript
localStorage.setItem("person", { name: "Ada" });
console.log(localStorage.getItem("person")); // "[object Object]" (trasigt!)
```

Vi löser detta med JSON i nästa laboration!

4. **Storleksbegränsning**: Ca 5-10 MB beroende på webbläsare.

5. **Synkront**: localStorage blockerar huvudtråden, så undvik att spara stora mängder data ofta.

### 5 - Utmaning: "Glöm mig"-knapp
Utöka din sida med en knapp som låter användaren radera sina sparade uppgifter.

1. Lägg till en knapp "Glöm mig" i din HTML.

2. När användaren klickar:
   * Ta bort det sparade namnet från localStorage
   * Rensa textfältet
   * Uppdatera hälsningen till något generiskt

3. Fundera på UX:
   * Ska du be om bekräftelse innan du raderar?
   * Ska knappen bara synas om det finns sparad data?

<details>
<summary>Tips för bekräftelse</summary>

```javascript
if (confirm("Är du säker på att du vill radera dina uppgifter?")) {
  localStorage.removeItem("userName");
  // ... rensa UI
}
```
</details>

### 6 - Utmaning: Spara tema-inställning
Skapa en möjlighet för användaren att välja mellan ljust och mörkt tema.

1. Lägg till en knapp eller toggle för att byta tema.

2. När användaren byter tema:
   * Uppdatera sidans utseende (t.ex. genom att lägga till/ta bort en CSS-klass på `<body>`)
   * Spara valet i localStorage

3. När sidan laddas:
   * Läs upp det sparade temat
   * Applicera det innan sidan renderas (för att undvika "flash")

<details>
<summary>Tips för tema-implementation</summary>

CSS:
```css
body.dark-theme {
  background-color: #1a1a1a;
  color: #f0f0f0;
}
```

JavaScript:
```javascript
// Läs vid sidladdning
const savedTheme = localStorage.getItem("theme");
if (savedTheme === "dark") {
  document.body.classList.add("dark-theme");
}

// Spara vid byte
function toggleTheme() {
  document.body.classList.toggle("dark-theme");
  const isDark = document.body.classList.contains("dark-theme");
  localStorage.setItem("theme", isDark ? "dark" : "light");
}
```
</details>

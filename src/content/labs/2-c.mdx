### 1 - Grunderna i localStorage
`localStorage` är ett enkelt nyckel-värde-lager som finns inbyggt i alla moderna webbläsare. Värdena som sparas går att läsa ut på alla sidor från samma ursprung (samma domän), i praktiken betyder det samma webbplats. Data i `localStorage` sparas som strängar och finns kvar tills de tas bort via kod.

**Exempel:**
```javascript
// Spara ett värde under nyckeln "greeting"
localStorage.setItem("greeting", "Hej världen!");

// Läsa värdet kopplat till nyckeln "greeting"
const message = localStorage.getItem("greeting");
console.log(message); // "Hej världen!"

// Ta bort ett värde
localStorage.removeItem("greeting");

// Rensa allt
localStorage.clear();
```

Öppna även DevTools och hitta var localStorage-data visas där:
   * **Application**-fliken (Chrome) eller **Storage**-fliken (Firefox)
   * Expandera **Local Storage**
   * Ha gärna den fliken öppen när du kör koden för att se hur data läggs till och tas bort när du testa övningarna nedan.

### 2 - Kom ihåg besökarens namn
Nu ska vi lägga in ett textfält som kommer ihåg besökarens namn mellan sidladdningar.

#### Övning
1. Börja i `index.html` och lägg till ett textfält där användaren kan skriva sitt namn (ge det ett id, t.ex. `nameInput`).

2. Implementera JavaScript som:
   * Läser ett eventuellt sparat namn från localStorage när sidan laddas och fyller i textfältet med det om det finns (använd `localStorage.getItem` för att läsa värdet, och elementets `value`-egenskap för att sätta det)
   * Sparar namnet i localStorage direkt när användaren skriver (koppla en lyssnare till `input`-eventet på textfältet, och använd `localStorage.setItem` för att spara värdet)

3. Testa genom att skriva ditt namn, ladda om sidan - namnet ska finnas kvar i textfältet.

**Extra:** Lägg till en "Rensa"-knapp som tar bort det sparade namnet och tömmer textfältet.

<details>
<summary>Lösningsförslag</summary>

index.html:
```html
<!-- [...] resten av HTML-koden -->

<label for="nameInput">Namn: </label>
<input type="text" id="nameInput" placeholder="Skriv ditt namn här">
```

index.js:
```javascript
const nameInput = document.getElementById('nameInput');

// När sidan laddas: läs eventuellt sparat namn
const savedName = localStorage.getItem("name");
if (savedName) {
  nameInput.value = savedName;
}

// Spara när användaren skriver
nameInput.addEventListener("input", function() {
  localStorage.setItem("name", nameInput.value);
});
```

### 4 - Begränsningar och viktiga detaljer
localStorage har några viktiga begränsningar att känna till:

#### Endast strängar
```javascript
localStorage.setItem("age", 25);
const age = localStorage.getItem("age");
console.log(typeof age); // "string" (inte "number"!)
console.log(age + 5);    // "255" (strängkonkatenering, inte addition!)

// Lösning för tal:
const correctAge = Number(localStorage.getItem("age"));
console.log(correctAge + 5); // 30
```

#### Andra begränsningar

* **Objekt fungerar inte direkt**: `localStorage.setItem("obj", {name: "Ada"})` blir `"[object Object]"` - vi löser detta med JSON i nästa labb
* **Storleksbegränsning**: Ca 5-10 MB beroende på webbläsare
* **Säkerhet**: Spara aldrig känsliga uppgifter som lösenord. Som du såg ovan så sparas allt i klartext och kan lätt läsas av andra skript på sidan eller via utvecklarpanelen.

### 5 - Utmaning: Användarpreferenser
Lägg in fält med vilka användaren kan anpassa olika inställningar som sparas mellan besök.

#### Uppgift
Exempel på inställningar som användaren skulle kunna göra:

1. **Tema-väljare**: Radio-buttons för "Ljust", "Mörkt", "Auto"
3. **Textsstorlek**: Slider eller radio-knappar för "Liten", "Normal", "Stor"
4. **Namn**: Textfält (som du redan gjort)

* Alla inställningar ska sparas i localStorage direkt när de ändras
* Inställningarna ska tillämpas när sidan laddas
* CSS ska ändras baserat på användarens val
* En "Återställ allt"-knapp som rensar alla inställningar

#### Tips för implementation
* Använd olika localStorage-nycklar för varje inställning
* Skapa funktioner som `applyTheme()`, `applyFontSize()` osv.
* Testa alla kombinationer av inställningar

<details>
<summary>Exempel på tema-implementation</summary>

index.html:
```html
<!-- [...] resten av HTML-koden -->

<h2>Välj tema:</h2>
<label>
  <input type="radio" name="theme" value="light"> Ljust
</label>
<label>
  <input type="radio" name="theme" value="dark"> Mörkt
</label>
```

index.js:
```javascript
const themeRadios = document.querySelectorAll('input[name="theme"]');
let savedTheme =  "light"; // default värde
if (localStorage.getItem('selectedTheme')) {
  savedTheme = localStorage.getItem('selectedTheme');
}

// Tillämpa sparat tema
document.body.className = savedTheme + '-theme';
document.querySelector(`input[value="${savedTheme}"]`).checked = true;

// Lyssna på ändringar
themeRadios.forEach(radio => {
  radio.addEventListener('change', function() {
    localStorage.setItem('selectedTheme', this.value);
    document.body.className = this.value + '-theme';
  });
});
```

CSS:
```css
.light-theme {
  background: white;
  color: black;
}

.dark-theme {
  background: #1a1a1a;
  color: #f0f0f0;
}
```

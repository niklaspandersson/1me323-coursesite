Arrow-funktioner (även kallade pilfunktioner) är ett kortare sätt att skriva funktioner i JavaScript. De introducerades i ES6 och är särskilt praktiska när du arbetar med eventhantarere och callbacks, som vid `setTimeout()` och `Promise.then()` som vi kommer att använda när vi börjar läsa in data dynamiskt i nästa labb.

### 1 - Grundläggande syntax
En vanlig funktion kan skrivas om till en arrow-funktion.

#### Vanlig funktion
```javascript
function greet(name) {
  return "Hej " + name + "!";
}
```

#### Arrow-funktion
```javascript
const greet = (name) => {
  return "Hej " + name + "!";
};
```

Skillnader:
* Inget `function`-nyckelord
* En pil `=>` mellan parametrarna och funktionskroppen
* Funktionen sparas i en variabel

**Uppgift**: Skriv om följande funktioner till arrow-funktioner:

```javascript
function double(n) {
  return n * 2;
}

function isEven(n) {
  return n % 2 === 0;
}

function sum(a, b) {
  return a + b;
}
```

<details>
<summary>Förslag på lösning</summary>

```javascript
const double = (n) => {
  return n * 2;
};

const isEven = (n) => {
  return n % 2 === 0;
};

const sum = (a, b) => {
  return a + b;
};
```
</details>

### 2 - Utelämna måsvingar (implicit return)
När funktionen bara består av ett enda uttryck som returneras kan du utelämna både måsvingarna `{}` och `return`. Detta kallas *implicit return*.

```javascript
// Med måsvingar och return
const double = (n) => {
  return n * 2;
};

// Utan måsvingar - implicit return
const double = (n) => n * 2;
```

**OBS**: Detta fungerar som sagt bara när funktionskroppen är ett enda uttryck. Om du har flera satser eller behöver mellansteg måste du använda måsvingar.

**Uppgift**: Förenkla dina funktioner från förra övningen genom att använda implicit return:

<details>
<summary>Förslag på lösning</summary>

```javascript
const double = (n) => n * 2;
const isEven = (n) => n % 2 === 0;
const sum = (a, b) => a + b;
```
</details>

### 3 - Utelämna parenteser
När funktionen har **exakt en parameter** kan du utelämna parenteserna runt parametern:

```javascript
// Med parenteser
const double = (n) => n * 2;

// Utan parenteser
const double = n => n * 2;
```

**OBS**: Parenteser krävs fortfarande om du har:
* Noll parametrar: `() => console.log("Hej")`
* Två eller fler parametrar: `(a, b) => a + b`

**Uppgift**: Vilka av följande kan förenklas genom att ta bort parenteserna?

```javascript
const square = (x) => x * x;
const sayHello = () => "Hej!";
const multiply = (a, b) => a * b;
const increment = (n) => n + 1;
```

<details>
<summary>Förslag på lösning</summary>

```javascript
const square = x => x * x;         // ✓ En parameter - kan förenklas
const sayHello = () => "Hej!";     // ✗ Noll parametrar - parenteser krävs
const multiply = (a, b) => a * b;  // ✗ Två parametrar - parenteser krävs
const increment = n => n + 1;      // ✓ En parameter - kan förenklas
```
</details>

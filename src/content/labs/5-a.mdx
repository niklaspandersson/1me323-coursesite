<main>
DOM (Document Object Model) är webbläsarens representation av HTML-dokumentet som ett träd av objekt. Med JavaScript kan vi skapa, modifiera och ta bort element i detta träd.

### 0 - Förberedelser
Skapa en ny mapp `5a` i din `labs`-mapp med `index.html` och `main.js`. Skapa en grundläggande HTML-struktur med en tom `<main>`-container.

### 1 - Skapa element med createElement()
`document.createElement()` skapar ett nytt element i minnet (det visas inte förrän vi lägger till det i DOM).

```javascript
// Skapa ett nytt p-element
const paragraph = document.createElement('p');

// Sätt textinnehåll
paragraph.textContent = 'Hej från JavaScript!';

// Lägg till i DOM
document.body.appendChild(paragraph);
```

#### Övning
1. Skapa ett `<h1>`-element med texten "Min dynamiska sida"
2. Skapa ett `<p>`-element med en kort beskrivning
3. Lägg till båda i `<main>`-containern

<details>
<summary>Lösningsförslag</summary>

```javascript
const main = document.querySelector('main');

const heading = document.createElement('h1');
heading.textContent = 'Min dynamiska sida';

const description = document.createElement('p');
description.textContent = 'Denna sida är skapad helt med JavaScript!';

main.appendChild(heading);
main.appendChild(description);
```
</details>

### 2 - Sätta attribut och klasser
Element kan ha attribut (src, href, id) och CSS-klasser.

```javascript
const link = document.createElement('a');
link.textContent = 'Klicka här';

// Sätt attribut
link.setAttribute('href', 'https://example.com');
link.setAttribute('target', '_blank');

// Eller direkt som egenskaper
link.href = 'https://example.com';
link.id = 'my-link';

// CSS-klasser
link.classList.add('btn');
link.classList.add('btn-primary');
// eller
link.className = 'btn btn-primary';
```

#### Övning
Skapa en bild (`<img>`) med:
- `src` till en placeholder-bild (t.ex. `https://picsum.photos/200/150`)
- `alt`-text
- Klassen `thumbnail`

<details>
<summary>Lösningsförslag</summary>

```javascript
const img = document.createElement('img');
img.src = 'https://picsum.photos/200/150';
img.alt = 'En slumpmässig bild';
img.classList.add('thumbnail');

document.querySelector('main').appendChild(img);
```
</details>

### 3 - Bygga strukturer med appendChild()
Du kan bygga komplexa strukturer genom att nästla `appendChild()`.

```javascript
// Skapa en lista
const ul = document.createElement('ul');

const items = ['Äpple', 'Banan', 'Citron'];

for (const item of items) {
  const li = document.createElement('li');
  li.textContent = item;
  ul.appendChild(li);  // Lägg li i ul
}

document.querySelector('main').appendChild(ul);  // Lägg ul i main
```

#### Övning
Skapa ett navigeringselement (`<nav>`) med:
- En `<ul>` med tre `<li>`-element
- Varje `<li>` innehåller en `<a>` med href och text

```javascript
const navItems = [
  { text: 'Hem', href: '#home' },
  { text: 'Om', href: '#about' },
  { text: 'Kontakt', href: '#contact' }
];
```

<details>
<summary>Lösningsförslag</summary>

```javascript
const nav = document.createElement('nav');
const ul = document.createElement('ul');

for (const item of navItems) {
  const li = document.createElement('li');
  const a = document.createElement('a');
  a.textContent = item.text;
  a.href = item.href;
  li.appendChild(a);
  ul.appendChild(li);
}

nav.appendChild(ul);
document.body.prepend(nav);  // Lägg till först i body
```
</details>

### 4 - textContent vs innerHTML
Det finns två sätt att sätta innehåll i ett element:

```javascript
const div = document.createElement('div');

// textContent - säkert, behandlar allt som text
div.textContent = '<strong>Hej</strong>';
// Visar: <strong>Hej</strong> (som text)

// innerHTML - tolkar HTML (OBS: säkerhetsrisk!)
div.innerHTML = '<strong>Hej</strong>';
// Visar: Hej (i fetstil)
```

**Varning**: Använd inte `innerHTML` med användarinput - det kan leda till XSS-attacker.

```javascript
// FARLIGT - gör aldrig detta!
const userInput = '<script>alert("Hackad!")</script>';
div.innerHTML = userInput;

// SÄKERT
div.textContent = userInput;
```

### 5 - Ta bort element
Element kan tas bort från DOM på flera sätt:

```javascript
// Ta bort specifikt element
const element = document.querySelector('#to-remove');
element.remove();

// Ta bort barn från förälder
const parent = document.querySelector('#parent');
parent.removeChild(parent.firstChild);

// Töm alla barn
parent.innerHTML = '';
// eller
while (parent.firstChild) {
  parent.removeChild(parent.firstChild);
}
```

### 6 - Praktisk övning: Produktkort
Skapa en funktion som bygger ett produktkort med DOM-metoder.

#### Uppgift
1. Skapa funktionen `createProductCard(product)` som tar ett produktobjekt:
```javascript
const product = {
  name: 'Trådlösa hörlurar',
  price: 899,
  image: 'https://picsum.photos/200/150',
  inStock: true
};
```

2. Funktionen ska returnera ett komplett produktkort (`<article>`) med:
   - Bild
   - Produktnamn (h3)
   - Pris
   - Lagerstatus (med rätt klass)
   - "Köp"-knapp

3. Använd **endast** `createElement()`, `appendChild()`, och `textContent` - ingen `innerHTML`.

<details>
<summary>Lösningsförslag</summary>

```javascript
function createProductCard(product) {
  const article = document.createElement('article');
  article.classList.add('product-card');

  // Bild
  const img = document.createElement('img');
  img.src = product.image;
  img.alt = product.name;

  // Namn
  const name = document.createElement('h3');
  name.textContent = product.name;

  // Pris
  const price = document.createElement('p');
  price.classList.add('price');
  price.textContent = `${product.price} kr`;

  // Lagerstatus
  const stock = document.createElement('span');
  stock.classList.add('stock');
  stock.classList.add(product.inStock ? 'in-stock' : 'out-of-stock');
  stock.textContent = product.inStock ? 'I lager' : 'Slut';

  // Köp-knapp
  const button = document.createElement('button');
  button.textContent = 'Köp';
  button.disabled = !product.inStock;

  // Bygg ihop
  article.appendChild(img);
  article.appendChild(name);
  article.appendChild(price);
  article.appendChild(stock);
  article.appendChild(button);

  return article;
}

// Använd funktionen
const card = createProductCard(product);
document.querySelector('main').appendChild(card);
```
</details>

### 7 - Utmaning: Dynamisk lista med interaktivitet
Bygg en att-göra-lista med DOM-manipulation.

#### Uppgift
1. Skapa ett formulär med ett textfält och en "Lägg till"-knapp
2. När formuläret skickas:
   - Skapa ett nytt `<li>`-element med texten
   - Lägg till en "Ta bort"-knapp på varje item
   - Lägg till i listan
3. Ta bort-knappen ska ta bort sitt `<li>`-element

**Tips**: Använd event listeners på de skapade knapparna.

<details>
<summary>Lösningsförslag</summary>

```javascript
const form = document.getElementById('todo-form');
const input = document.getElementById('todo-input');
const list = document.getElementById('todo-list');

form.addEventListener('submit', (e) => {
  e.preventDefault();

  const text = input.value.trim();
  if (!text) return;

  // Skapa li
  const li = document.createElement('li');

  // Skapa span för text
  const span = document.createElement('span');
  span.textContent = text;

  // Skapa ta bort-knapp
  const deleteBtn = document.createElement('button');
  deleteBtn.textContent = 'Ta bort';
  deleteBtn.addEventListener('click', () => {
    li.remove();
  });

  // Bygg ihop
  li.appendChild(span);
  li.appendChild(deleteBtn);
  list.appendChild(li);

  // Rensa input
  input.value = '';
});
```
</details>

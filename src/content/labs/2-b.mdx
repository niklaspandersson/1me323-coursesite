### 2 - Konstruktor funktioner - en mall för objekt
En konstruktor funktion är en vanlig funktion som används som "mall" för att skapa objekt.

**Exempel:**
```javascript
// Konstruktor funktion (börjar med stor bokstav per konvention)
function Person(firstName, lastName, age) {
  this.firstName = firstName;
  this.lastName = lastName;
  this.age = age;
}

// Skapa objekt med 'new'-nyckelordet
const anna = new Person("Anna", "Andersson", 25);
const erik = new Person("Erik", "Eriksson", 30);
const maria = new Person("Maria", "Johansson", 28);

console.log(anna.firstName); // "Anna"
console.log(erik.age);       // 30
```

**Vad händer här?**
1. `new Person()` skapar ett nytt tomt objekt
2. `this` inuti funktionen refererar till det nya objektet
3. Egenskaper läggs till på objektet via `this.egenskap = värde`
4. Det nya objektet returneras automatiskt

#### Övning
1. Skapa en constructor function `Car` som tar parametrarna:
   * `brand` (märke)
   * `model` 
   * `year` (årsmodell)
   * `color` (färg)

2. Skapa tre olika bil-objekt från din constructor.

3. Logga ut informationen för varje bil.

```javascript

  this.brand = brand;
```

### 3 - Vad är `this`?
I en constructor function refererar `this` till det objekt som håller på att skapas.

**Visualisering av vad som händer:**
```javascript
function Person(name, age) {
  // new Person() skapar ett tomt objekt: {}
  // this refererar nu till detta objekt
  
  this.name = name;  // {} blir { name: "Anna" }
  this.age = age;    // { name: "Anna" } blir { name: "Anna", age: 25 }
  
  // Objektet returneras automatiskt
}

const anna = new Person("Anna", 25);
// anna är nu { name: "Anna", age: 25 }
```

4. **Fördjupning**: Kontrollera vad `this` refererar till utan `new`:

<details>
<summary>Förklaring av vad som händer utan 'new'</summary>

Utan `new`-nyckelordet:
- Inget nytt objekt skapas
- `this` refererar till `window` (globalt objekt) eller `undefined` (i strict mode)
- Du förorenar det globala scopet eller får fel
- Funktionen returnerar `undefined` istället för ett objekt

**Därför**: Använd alltid `new` med constructor functions!
</details>

### 4 - Metoder i constructor functions
Du kan även lägga till metoder (funktioner) i constructor functions.

**Exempel:**
```javascript
function Person(firstName, lastName) {
  this.firstName = firstName;
  this.lastName = lastName;
  
  // Metod som använder objektets egenskaper
  this.getFullName = function() {
    return this.firstName + " " + this.lastName;
  };
  
  this.introduce = function() {
    return `Hej, jag heter ${this.getFullName()}!`;
  };
}

const person = new Person("Ada", "Lovelace");
console.log(person.getFullName()); // "Ada Lovelace"
console.log(person.introduce());   // "Hej, jag heter Ada Lovelace!"
```

#### Övning
1. Utöka din `Car`-constructor med en metod `getDescription()` som returnerar en beskrivning som: "2018 Volvo V40 i blå färg".

2. Lägg till en metod `honk()` som loggar "Tut tut!" och bilens märke.

3. Skapa en `BankAccount`-constructor med:
   * Egenskaper: `owner` (kontoinnehavare), `balance` (saldo, startar med 0)
   * Metoder:
     - `deposit(amount)` - sätt in pengar
     - `withdraw(amount)` - ta ut pengar (bara om det finns tillräckligt saldo)
     - `getBalance()` - visa aktuellt saldo
     - `getInfo()` - visa kontoinformation

4. Skapa två bankkonton och testa alla metoder.

<details>
<summary>Lösningsförslag för BankAccount</summary>

```javascript
function BankAccount(owner) {
  this.owner = owner;
  this.balance = 0;
  
  this.deposit = function(amount) {
    if (amount > 0) {
      this.balance += amount;
      console.log(`Satte in ${amount} kr. Nytt saldo: ${this.balance} kr`);
    }
  };
  
  this.withdraw = function(amount) {
    if (amount > 0 && amount <= this.balance) {
      this.balance -= amount;
      console.log(`Tog ut ${amount} kr. Nytt saldo: ${this.balance} kr`);
    } else {
      console.log("Otillräckligt saldo eller ogiltigt belopp");
    }
  };
  
  this.getBalance = function() {
    return this.balance;
  };
  
  this.getInfo = function() {
    return `Konto för ${this.owner}, saldo: ${this.balance} kr`;
  };
}

const account1 = new BankAccount("Anna Andersson");
account1.deposit(1000);
account1.withdraw(300);
console.log(account1.getInfo());
```
</details>

### 5 - Constructor vs vanlig funktion
Viktiga skillnader att komma ihåg:

| Constructor Function | Vanlig Funktion |
|---------------------|----------------|
| Börjar med stor bokstav (konvention) | Börjar med liten bokstav |
| Anropas med `new` | Anropas direkt |
| `this` refererar till nytt objekt | `this` refererar till anroparen |
| Returnerar nytt objekt automatiskt | Måste explicit returnera värde |

#### Övning
**Debugging-övning**: Hitta och fixa problemen i denna kod:

```javascript
// Problem 1: Vad är fel här?
function calculator(initialValue) {
  this.value = initialValue;
  this.add = function(num) {
    this.value += num;
  };
}

const calc = calculator(10); // Utan 'new'
calc.add(5); // Vad händer?

// Problem 2: Vad händer här?
function Counter() {
  this.count = 0;
  this.increment = function() {
    this.count++;
  };
  return "Detta returneras istället"; // Explicit return
}

const counter = new Counter();
console.log(counter); // Vad blir resultatet?
```

<details>
<summary>Lösningar</summary>

**Problem 1**: Glömt `new`-nyckelordet. `calc` blir `undefined`.
```javascript
const calc = new calculator(10); // Lägg till 'new'
```

**Problem 2**: Explicit `return` av primitiv typ ignoreras i constructor functions, men returnar man ett objekt så används det istället för det skapade objektet. Bästa praxis är att inte ha explicit `return` alls i constructors.
```javascript
function Counter() {
  this.count = 0;
  this.increment = function() {
    this.count++;
  };
  // Ta bort explicit return
}
```
</details>

### 6 - Utmaning: Kontaktlista
Skapa en komplett kontaktlista-applikation.

#### Uppgift
1. **Constructor**: Skapa en `Contact`-constructor med:
   - `name`, `email`, `phone`, `company`
   - Metod `getDisplayInfo()` som returnerar formaterad information

2. **Data**: Skapa en array med minst 5 kontakter

3. **HTML**: Bygg en sida som visar alla kontakter

4. **Funktionalitet**: 
   - Visa alla kontakter i en snygg lista
   - Lägg till formulär för att skapa nya kontakter
   - Lägg till knapp för att uppdatera telefonnummer

**Extra utmaning**: Lägg till sök-funktionalitet för att filtrera kontakter.

<details>
<summary>Grund-struktur</summary>

```javascript
function Contact(name, email, phone, company) {
  this.name = name;
  this.email = email;
  this.phone = phone;
  this.company = company;
  
  this.getDisplayInfo = function() {
    return `
      <div class="contact">
        <h3>${this.name}</h3>
        <p>Email: ${this.email}</p>
        <p>Phone: ${this.phone}</p>
        <p>Company: ${this.company}</p>
      </div>
    `;
  };
  
  this.updatePhone = function(newPhone) {
    this.phone = newPhone;
  };
}

// Skapa kontakter
const contacts = [
  new Contact("Anna Andersson", "anna@example.com", "070-123-4567", "Tech AB"),
  new Contact("Erik Eriksson", "erik@example.com", "070-987-6543", "Design Studio"),
  // ... fler kontakter
];

// Visa kontakter
function displayContacts() {
  const container = document.getElementById('contacts');
  container.innerHTML = contacts.map(contact => 
    contact.getDisplayInfo()
  ).join('');
}
```

Metoder är funktioner som tillhör ett objekt. De kan använda nyckelordet `this` för att komma åt objektets egna egenskaper, vilket gör dem kraftfulla för att skapa självständiga, återanvändbara komponenter.

### 0 - Förberedelser
Skapa en ny mapp `2b` i din `labs`-mapp med `index.html` och `main.js`. Länka gärna in `global.css` från labs-roten.

### 1 - Skapa en metod
En metod är helt enkelt en funktion som är en egenskap på ett objekt. `this` refererar till objektet som metoden tillhör.

**Exempel:**
```javascript
const person = {
  firstName: "Grace",
  lastName: "Hopper",

  getFullName: function() {
    return this.firstName + " " + this.lastName;
  },

  // Kortare syntax (rekommenderas)
  introduce() {
    console.log(`Hej, jag heter ${this.firstName}!`);
  }
};

console.log(person.getFullName()); // "Grace Hopper"
person.introduce(); // "Hej, jag heter Grace!"
```

#### Övning
1. Skapa ett objekt `car` med egenskaperna:
   * `brand` (t.ex. "Volvo")
   * `model` (t.ex. "V40")
   * `year` (t.ex. 2018)

2. Lägg till en metod `getDescription()` som returnerar en sträng som beskriver bilen, t.ex. "2018 Volvo V40".

3. Lägg till en metod `honk()` som loggar "Tut tut!" till konsolen.

4. Testa båda metoderna.

<details>
<summary>Lösningsförslag</summary>

```javascript
const car = {
  brand: "Volvo",
  model: "V40", 
  year: 2018,

  getDescription() {
    return `${this.year} ${this.brand} ${this.model}`;
  },

  honk() {
    console.log("Tut tut!");
  }
};

console.log(car.getDescription()); // "2018 Volvo V40"
car.honk(); // "Tut tut!"
```
</details>

### 2 - Ett räknar-objekt
Nu ska vi skapa ett objekt som håller reda på ett värde och kan modifiera det.

#### Övning
1. Skapa ett objekt `counter` som håller reda på ett värde skall kunna räkna upp och ner:
   * Egenskap: `value` (startvärde 0)
   * Metod: `increase()` - ökar värdet med 1
   * Metod: `decrease()` - minskar med 1  
   * Metod: `reset()` - sätter värdet till 0

2. Testa alla metoder i konsolen.

<details>
<summary>Lösningsförslag</summary>

```javascript
const counter = {
  value: 0,

  increment() {
    this.value++;
  },

  decrement() {
    this.value--;
  },

  reset() {
    this.value = 0;
  }
};

// Testa metoderna
console.log("Värde initialt: "; counter.value); // 0
counter.increment();
console.log("Värde efter en ökning: "; counter.value); // 1
counter.increment();
console.log("Värde efter nästa ökning: "; counter.value); // 2
counter.decrement(); 
console.log("Värde efter minskning: "; counter.value); // 1
counter.reset();     
console.log("Värde efter reset: "; counter.value); // 0
```
</details>

3. Skapa ett enkelt användargränssnitt i `index.html` med:
   * Ett element som visar aktuellt värde
   * Knappar för att öka, minska och nollställa värdet (efter varje uppdatering skall det aktuella värdet visas på sidan)

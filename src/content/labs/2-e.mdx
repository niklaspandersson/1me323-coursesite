<main>
Ternary-operatorn (villkorsoperatorn) ger dig ett kortare sätt att skriva enkla if/else-satser. Den är särskilt användbar när du vill tilldela ett värde baserat på ett villkor.

### 0 - Förberedelser
Skapa en ny mapp `2e` i din `labs`-mapp med `index.html` och `main.js`. Länka gärna in `global.css`.

### 1 - Grundsyntax
Ternary-operatorn har tre delar:

```javascript
villkor ? värdOmSant : värdOmFalskt
```

**Exempel:**
```javascript
const age = 20;

// Med if/else
let status;
if (age >= 18) {
  status = "vuxen";
} else {
  status = "minderårig";
}

// Med ternary - samma resultat på en rad
const status = age >= 18 ? "vuxen" : "minderårig";
```

#### Övning
1. Skapa en variabel `score` med ett tal mellan 0-100.
2. Använd ternary för att sätta `result` till `"Godkänt"` om score >= 50, annars `"Underkänt"`.
3. Logga resultatet.

<details>
<summary>Lösningsförslag</summary>

```javascript
const score = 72;
const result = score >= 50 ? "Godkänt" : "Underkänt";
console.log(`Poäng: ${score} - ${result}`);
```
</details>

### 2 - Ternary i template literals
Ternary blir extra kraftfull tillsammans med template literals för att bygga dynamisk HTML.

**Exempel:**
```javascript
const isLoggedIn = true;
const username = "Anna";

const greeting = `
  <div class="header">
    ${isLoggedIn ? `<span>Välkommen, ${username}!</span>` : '<a href="/login">Logga in</a>'}
  </div>
`;
```

#### Övning
Skapa en funktion `createProductCard(product)` som tar ett produktobjekt och returnerar HTML.

1. Produkten har egenskaperna: `name`, `price`, `inStock` (boolean)
2. Om produkten finns i lager, visa "I lager" med grön färg
3. Om produkten är slut, visa "Slut i lager" med röd färg och dämpa hela kortet

```javascript
const product = {
  name: "Trådlösa hörlurar",
  price: 899,
  inStock: true
};
```

<details>
<summary>Lösningsförslag</summary>

```javascript
function createProductCard(product) {
  return `
    <div class="product-card ${product.inStock ? '' : 'out-of-stock'}">
      <h3>${product.name}</h3>
      <p class="price">${product.price} kr</p>
      <span class="stock ${product.inStock ? 'in-stock' : 'sold-out'}">
        ${product.inStock ? 'I lager' : 'Slut i lager'}
      </span>
    </div>
  `;
}

// Testa
document.body.innerHTML = createProductCard(product);
```
</details>

### 3 - Praktisk övning: Toggle-knapp
Bygg en knapp som växlar mellan två tillstånd.

#### Uppgift
1. Skapa en knapp i HTML med texten "Visa mer"
2. Skapa en `<div>` med dolt innehåll (`display: none`)
3. När knappen klickas:
   - Växla synligheten på innehållet
   - Ändra knapptexten mellan "Visa mer" och "Visa mindre"

Använd ternary för att bestämma knapptexten.

<details>
<summary>Lösningsförslag</summary>

```javascript
const button = document.querySelector('#toggle-btn');
const content = document.querySelector('#hidden-content');
let isVisible = false;

button.addEventListener('click', function() {
  isVisible = !isVisible;
  content.style.display = isVisible ? 'block' : 'none';
  button.textContent = isVisible ? 'Visa mindre' : 'Visa mer';
});
```
</details>

### 4 - Varning: Undvik nästlade ternaries
Det går att nästla ternary-operatorer, men det blir snabbt svårläst.

```javascript
// Svårläst - undvik detta
const grade = score >= 90 ? 'A' : score >= 80 ? 'B' : score >= 70 ? 'C' : 'F';

// Bättre: använd if/else eller en funktion
function getGrade(score) {
  if (score >= 90) return 'A';
  if (score >= 80) return 'B';
  if (score >= 70) return 'C';
  return 'F';
}
```

**Tumregel**: Använd ternary för enkla ja/nej-val. För mer komplexa villkor, använd if/else.

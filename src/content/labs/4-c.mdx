Hittills har alla egenskaper i våra klasser varit fritt åtkomliga utifrån — vem som helst kan läsa och ändra dem direkt. Det kan leda till problem: ingenting hindrar någon från att sätta ett banksaldo till ett negativt värde, eller en ålder till -5. **Inkapsling** handlar om att skydda ett objekts interna data och kontrollera hur den kan ändras.

### 1 - Problemet med öppna egenskaper
Låt oss titta på ett exempel som visar varför det kan vara problematiskt att alla egenskaper är publika.

```javascript
class BankAccount {
  constructor(owner, balance) {
    this.owner = owner;
    this.balance = balance;
  }
}

const account = new BankAccount("Anna", 1000);

// Vem som helst kan göra detta:
account.balance = -999999;
console.log(account.balance); // -999999 — det borde inte vara möjligt!
```

Ingenting i koden förhindrar att saldot sätts till ett ogiltigt värde. I ett riktigt system vore detta ett allvarligt problem.

### 2 - Privata fält med `#`
JavaScript har stöd för **privata fält** som inte kan nås utifrån klassen. De markeras med `#` framför namnet.

**Exempel:**
```javascript
class BankAccount {
  #balance;

  constructor(owner, balance) {
    this.owner = owner;
    this.#balance = balance;
  }

  getBalance() {
    return this.#balance;
  }

  deposit(amount) {
    if (amount > 0) {
      this.#balance += amount;
    }
  }
}

const account = new BankAccount("Anna", 1000);
console.log(account.getBalance()); // 1000
account.deposit(500);
console.log(account.getBalance()); // 1500

// Detta fungerar INTE — privata fält kan inte nås utifrån:
// console.log(account.#balance); // SyntaxError!
```

Notera att privata fält **måste deklareras** i klassen (raden `#balance;` i toppen) innan de kan användas i konstruktorn.

### 3 - Getters
En **getter** är en speciell metod som ser ut som en egenskap när den används. Den definieras med nyckelordet `get` framför metodnamnet. Getters är användbara när du vill kontrollera åtkomst till privata fält, men de kan också till exempel användas för att beräkna ett värde utifrån andra egenskaper.

**Exempel:**
```javascript
class Circle {
  #radius;

  constructor(radius) {
    this.#radius = radius;
  }

  get radius() {
    return this.#radius;
  }

  get area() {
    return Math.PI * this.#radius ** 2;
  }

  get circumference() {
    return 2 * Math.PI * this.#radius;
  }
}

const circle = new Circle(5);

// Getters anropas utan parenteser — de ser ut som egenskaper:
console.log(circle.radius);        // 5
console.log(circle.area);          // 78.539...
console.log(circle.circumference); // 31.415...
```

Notera att vi skriver `circle.area`, **inte** `circle.area()`. Gettern ser ut som en egenskap men kör kod i bakgrunden.

```javascript
console.log(person.initials); // "A.L."
```

### 4 - Setters
En **setter** definieras med nyckelordet `set` och körs automatiskt när du tilldelar ett värde. Här kan du exempelvis lägga in **validering** — regler som kontrollerar att datan är giltig innan den sparas. På så sätt kan vi tillåta att någon ändrar ett visst värde, men samtidigt skydda mot ogiltiga värden.

**Exempel:**
```javascript
class Thermostat {
  #temperature;

  constructor(temperature) {
    this.#temperature = temperature;
  }

  get temperature() {
    return this.#temperature;
  }

  set temperature(value) {
    if (value < 0 || value > 120) {
      console.log("Ogiltig temperatur!");
      return;
    }
    this.#temperature = value;
  }
}

const thermostat = new Thermostat(80);
console.log(thermostat.temperature); // 80

thermostat.temperature = 20;
console.log(thermostat.temperature); // 20

thermostat.temperature = 250; // "Ogiltig temperatur!"
console.log(thermostat.temperature); // 20 — oförändrad
```

Settern körs automatiskt vid tilldelning (`thermostat.temperature = 20`). Det ser ut som en vanlig tilldelning, men i bakgrunden körs vår valideringskod.

```javascript
  #price;

    return this.#name;
```

### 5 - Allt tillsammans
Låt oss kombinera privata fält, getters och setters i en mer komplett klass.

#### Övning
1. Skapa en klass `Student` med:
   * Privata fält `#name`, `#grades` (en array med betyg, startar tom).
   * En getter `name`.
   * En metod `addGrade(grade)` som bara accepterar tal mellan 0 och 100.
   * En getter `average` som beräknar och returnerar medelvärdet av betygen (eller 0 om inga betyg finns).
   * En getter `status` som returnerar `"Godkänd"` om medelvärdet är minst 50, annars `"Underkänd"`.
2. Skapa en student, lägg till flera betyg (inklusive ett ogiltigt), och logga namn, medelvärde och status.

<details>
<summary>Lösningsförslag</summary>

```javascript
class Student {
  #name;
  #grades;

  constructor(name) {
    this.#name = name;
    this.#grades = [];
  }

  get name() {
    return this.#name;
  }

  addGrade(grade) {
    if (typeof grade !== "number" || grade < 0 || grade > 100) {
      console.log("Betyget måste vara ett tal mellan 0 och 100!");
      return;
    }
    this.#grades.push(grade);
  }

  get average() {
    if (this.#grades.length === 0) return 0;
    let sum = 0;
    for (const grade of this.#grades) {
      sum += grade;
    }
    return sum / this.#grades.length;
  }

  get status() {
    return this.average >= 50 ? "Godkänd" : "Underkänd";
  }
}

const student = new Student("Maja");
student.addGrade(75);
student.addGrade(88);
student.addGrade(62);
student.addGrade(-5); // "Betyget måste vara ett tal mellan 0 och 100!"

console.log(student.name);    // "Maja"
console.log(student.average); // 75
console.log(student.status);  // "Godkänd"
```
</details>

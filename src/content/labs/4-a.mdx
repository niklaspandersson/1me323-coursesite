#### Defaultvärden för argument
Standardvärden (default values) låter oss ange vad en parameter ska ha för värde om inget skickas med vid anropet. Detta är användbart för att göra vissa argument valfria och för att säkerställa att variabler alltid har ett giltigt startvärde.

**Syntax:**
```javascript
constructor(name, age = 0) { ... }
```

**Viktig regel:** Parametrar med defaultvärden måste placeras **efter** obligatoriska parametrar i listan. Om du lägger dem före kan JavaScript inte automatiskt fylla i dem korrekt när du utelämnar argument.
</aside>

### 1 - Problemet med objekt-literaler
Innan vi tittar på klasser, låt oss se varför de behövs. Tänk dig att du ska skapa flera djur-objekt:

```javascript
const dog1 = {
  name: "Fido",
  species: "Hund",
  age: 3
};

const dog2 = {
  name: "Rex",
  species: "Hund",
  age: 5
};

const dog3 = {
  name: "Bella",
  species: "Hund",
  age: 2
};
```

Alla tre objekten har exakt samma struktur — `name`, `species` och `age` — men vi upprepar strukturen varje gång. Lite samma problem som vi hade med upprepad html tidigare. Varje gång vi börjar upprepa oss introducerar vi risk för fel och inkonsekvenser. Och om vi dessutom vill lägga till en ny egenskap måste vi ändra på varje ställe. Det här är ett av problemen klasser löser.

### 2 - Din första klass
En klass definieras med nyckelordet `class`. Inuti klassen finns en speciell metod som heter `constructor` — det är den som körs automatiskt när ett nytt objekt skapas. I konstruktorn använder vi `this` för att sätta egenskaper på det nya objektet.

**Exempel:**
```javascript
class Animal {
  constructor(name, species, age) {
    this.name = name;
    this.species = species;
    this.age = age;
  }
}
```

Här definierar `Animal` en mall som säger: "Varje djur har ett namn, en art och en ålder." Konstruktorn tar emot dessa värden som parametrar och sparar dem som egenskaper på objektet med `this`.

För att skapa ett objekt från klassen använder vi nyckelordet `new`:

```javascript
const dog1 = new Animal("Fido", "Hund", 3);
const dog2 = new Animal("Rex", "Hund", 5);
const dog3 = new Animal("Bella", "Hund", 2);

console.log(dog1.name); // "Fido"
console.log(dog2.age);  // 5
```

Varje anrop av `new Animal(...)` skapar ett **nytt, unikt objekt** (en *instans*) med de egenskaper vi anger. Klassen är mallen, objekten är de faktiska sakerna som skapas från mallen.

### 3 - Konstruktorn bestämmer strukturen
Konstruktorn kan göra mer än att bara spara parametrar. Du kan sätta standardvärden, beräkna egenskaper eller lägga till egenskaper som inte kommer från parametrarna.

**Exempel:**
```javascript
class Player {
  constructor(name) {
    this.name = name;
    this.score = 0;       // Alla spelare börjar med 0 poäng
    this.isAlive = true;  // Alla spelare börjar som levande
  }
}

const p1 = new Player("Alice");
console.log(p1.name);    // "Alice"
console.log(p1.score);   // 0
console.log(p1.isAlive); // true
```

Här behöver vi bara ange spelarens namn — `score` och `isAlive` sätts automatiskt av konstruktorn.

### 4 - Klasser och arrayer
En vanlig användning av klasser är att skapa många instanser och samla dem i en array. Detta ger oss en lista av objekt med samma struktur — mycket användbart för att visa data i en tabell, ett galleri eller liknande.

**Exempel:**
```javascript
class Book {
  constructor(title, author, pages) {
    this.title = title;
    this.author = author;
    this.pages = pages;
  }
}

const books = [
  new Book("Frankenstein", "Mary Shelley", 280),
  new Book("1984", "George Orwell", 328),
  new Book("Dune", "Frank Herbert", 412)
];

// Logga alla boktitlar
for (const book of books) {
  console.log(book.title);
}
```

#### Övning
1. Skapa en klass `Movie` med en konstruktor som tar emot `title`, `director` och `rating` (betyg 1–10).
2. Skapa en array `movies` med minst fyra filmer.
3. Använd en `for...of`-loop för att logga alla filmers titlar och betyg i formatet `"Titel: X/10"`.
4. Visa filmerna på din HTML-sida genom att generera HTML med template-strängar och `innerHTML`.

<details>
<summary>Lösningsförslag</summary>

```javascript
class Movie {
  constructor(title, director, rating) {
    this.title = title;
    this.director = director;
    this.rating = rating;
  }
}

const movies = [
  new Movie("Inception", "Christopher Nolan", 8),
  new Movie("Spirited Away", "Hayao Miyazaki", 8),
  new Movie("Parasite", "Bong Joon-ho", 7),
  new Movie("The Matrix", "Wachowski-systrarna", 9)
];

for (const movie of movies) {
  console.log(`${movie.title}: ${movie.rating}/10`);
}

// Visa på sidan
const container = document.getElementById("movies");
let html = "<h2>Mina filmer</h2><ul>";
for (const movie of movies) {
  html += `<li><strong>${movie.title}</strong> (${movie.director}) - ${movie.rating}/10</li>`;
}
html += "</ul>";
container.innerHTML = html;
```
</details>

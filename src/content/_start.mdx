## Datadrivna dynamiska webbsidor
I kursen forstätter vi jobba med programspråket JavaScript, tillsammans med HTML och CSS. Fokuset i den här kursen är data. Hur vi kan bygga upp dynamiska gränssnitt utifrån data, hur vi kan läsa in data från olika källor och i viss mån även hur vi kan skicka data till olika tjänster.
